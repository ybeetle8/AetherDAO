# AE-Staking 本地测试时间配置指南

## 概述

在本地节点测试 AE-Staking 合约时，质押周期（7天、30天、90天等）太长不利于快速测试。本指南说明如何创建测试版本的合约，将时间单位从"天"改为"秒"，以便快速验证功能。

## 问题分析

### 当前时间配置

合约采用了抽象基类 + 环境特定实现的架构：

- **StakingBase.sol**: 抽象基类，包含所有核心逻辑
- **Staking.sol**: 主网实现，定义生产环境的时间常量

在 [Staking.sol](../contracts/AE-Staking/src/mainnet/Staking.sol) 中，时间相关配置如下：

```solidity
// 质押周期（主网模式：天）
function getStakePeriod7D() internal pure override returns (uint256) {
    return 7 days;  // 7天 = 604,800秒
}

function getStakePeriod30D() internal pure override returns (uint256) {
    return 30 days;  // 30天 = 2,592,000秒
}

// ... 其他周期

// 复利计算时间单位（主网：每天）
function getCompoundTimeUnit() internal pure override returns (uint256) {
    return 1 days;  // 86,400秒
}
```

### 关键时间参数

1. **质押周期** (Staking Periods)
   - 7天: `7 days` (604,800秒)
   - 30天: `30 days` (2,592,000秒)
   - 90天: `90 days` (7,776,000秒)
   - 180天: `180 days` (15,552,000秒)
   - 365天: `365 days` (31,536,000秒)

2. **复利时间单位** (Compound Time Unit)
   - 主网: `1 days` (86,400秒)
   - 用于计算复利周期数: `stakingDuration / getCompoundTimeUnit()`

3. **APY利率** (已经是正确的日复利率)
   - 7天: 1.006 (0.6%/天)
   - 30天: 1.009 (0.9%/天)
   - 90天: 1.011 (1.1%/天)
   - 180天: 1.015 (1.5%/天)
   - 365天: 1.020 (2.0%/天)

## 解决方案：创建测试版本合约

### 步骤 1: 创建 StakingTestnet.sol

创建一个新的测试网合约，继承 `StakingBase`，但使用秒作为时间单位。

**文件路径**: `contracts/AE-Staking/src/testnet/StakingTestnet.sol`

```solidity
// SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.20;

import {StakingBase} from "../abstract/StakingBase.sol";

/**
 * @title StakingTestnet - Testnet implementation for local testing
 * @notice Testing environment with accelerated time (seconds instead of days)
 * @dev Use this for local testing only. Time units are in seconds for faster testing.
 */
contract StakingTestnet is StakingBase {
    // =========================================================================
    // CONSTRUCTOR
    // =========================================================================

    constructor(
        address _usdt,
        address _router,
        address _rootAddress,
        address _feeRecipient,
        address _educationFundAddress
    ) StakingBase(_usdt, _router, _rootAddress, _feeRecipient, _educationFundAddress) {}

    // =========================================================================
    // ENVIRONMENT SPECIFIC CONSTANTS - TESTNET VALUES (ACCELERATED TIME)
    // =========================================================================

    // APY Rates (Same as mainnet - daily compounding rates)
    function getAPYRate7D() internal pure override returns (uint256) {
        return 1006000000000000000; // 0.6% per time unit
    }

    function getAPYRate30D() internal pure override returns (uint256) {
        return 1009000000000000000; // 0.9% per time unit
    }

    function getAPYRate90D() internal pure override returns (uint256) {
        return 1011000000000000000; // 1.1% per time unit
    }

    function getAPYRate180D() internal pure override returns (uint256) {
        return 1015000000000000000; // 1.5% per time unit
    }

    function getAPYRate365D() internal pure override returns (uint256) {
        return 1020000000000000000; // 2% per time unit
    }

    // Staking Periods (Testnet mode: SECONDS for fast testing)
    // 建议: 1天 = 30秒，方便快速测试
    function getStakePeriod7D() internal pure override returns (uint256) {
        return 7 * 30; // 210秒 (3.5分钟) 代表 7天
    }

    function getStakePeriod30D() internal pure override returns (uint256) {
        return 30 * 30; // 900秒 (15分钟) 代表 30天
    }

    function getStakePeriod90D() internal pure override returns (uint256) {
        return 90 * 30; // 2700秒 (45分钟) 代表 90天
    }

    function getStakePeriod180D() internal pure override returns (uint256) {
        return 180 * 30; // 5400秒 (90分钟) 代表 180天
    }

    function getStakePeriod365D() internal pure override returns (uint256) {
        return 365 * 30; // 10950秒 (182.5分钟) 代表 365天
    }

    // Team Thresholds (Same as mainnet)
    function getTeamThresholdTier1() internal pure override returns (uint256) {
        return 3_000 ether; // V1
    }

    function getTeamThresholdTier2() internal pure override returns (uint256) {
        return 10_000 ether; // V2
    }

    function getTeamThresholdTier3() internal pure override returns (uint256) {
        return 30_000 ether; // V3
    }

    function getTeamThresholdTier4() internal pure override returns (uint256) {
        return 100_000 ether; // V4
    }

    function getTeamThresholdTier5() internal pure override returns (uint256) {
        return 300_000 ether; // V5
    }

    function getTeamThresholdTier6() internal pure override returns (uint256) {
        return 1_000_000 ether; // V6
    }

    function getTeamThresholdTier7() internal pure override returns (uint256) {
        return 3_000_000 ether; // V7
    }

    function getTeamThresholdTier8() internal pure override returns (uint256) {
        return 10_000_000 ether; // V8
    }

    function getTeamThresholdTier9() internal pure override returns (uint256) {
        return 30_000_000 ether; // V9
    }

    // EOA check - disabled for testnet (allow contract testing)
    function shouldCheckEOA() internal pure override returns (bool) {
        return false;
    }

    // Compound Interest Time Unit - 30 seconds for testnet (represents 1 day)
    function getCompoundTimeUnit() internal pure override returns (uint256) {
        return 30; // 30秒代表1天，用于复利计算
    }
}
```

### 步骤 2: 时间换算说明

测试版本采用 **1天 = 30秒** 的换算比例：

| 主网周期 | 主网时间 | 测试时间 | 实际等待 |
|---------|---------|---------|---------|
| 7天     | 7 days  | 210秒   | 3.5分钟 |
| 30天    | 30 days | 900秒   | 15分钟  |
| 90天    | 90 days | 2700秒  | 45分钟  |
| 180天   | 180 days| 5400秒  | 90分钟  |
| 365天   | 365 days| 10950秒 | 182.5分钟|

**复利计算**：
- 主网: 每86,400秒（1天）计算一次复利
- 测试: 每30秒计算一次复利
- 换算比例: 2,880倍加速 (86400/30)

### 步骤 3: 修改部署脚本

在部署脚本中使用测试版本合约。

**示例**: 修改 `scripts/deploySYI.js` 或创建新的测试部署脚本

```javascript
// 原来的主网部署
// const Staking = await ethers.getContractFactory("Staking");

// 改为测试网部署
const Staking = await ethers.getContractFactory("StakingTestnet");

// 其余部署逻辑保持不变
const staking = await Staking.deploy(
    usdtAddress,
    routerAddress,
    rootAddress,
    feeRecipient,
    educationFundAddress
);
```

### 步骤 4: 测试流程

```bash
# 1. 编译合约（包含新的 StakingTestnet）
npx hardhat compile

# 2. 启动本地测试网络
npx hardhat node --hostname 0.0.0.0 --port 8545 --fork https://rpc.tornadoeth.cash/bsc --fork-block-number 64340000

# 3. 部署测试版本（在另一个终端）
npx hardhat run scripts/deploySYI.js --network localhost

# 4. 运行测试
npx hardhat run scripts/testSYIStaking.js --network localhost

# 5. 测试质押和提取
# - 质押后等待 210秒（3.5分钟）即可提取 7天期的质押
# - 使用 hardhat 的时间操作可以快进时间
```

### 步骤 5: 使用 Hardhat 时间操作快速测试

在测试脚本中，可以使用 Hardhat 的时间操作功能：

```javascript
const { time } = require("@nomicfoundation/hardhat-network-helpers");

// 质押
await staking.stake(amount, 0); // 0 = 7天期

// 快进 210秒
await time.increase(210);

// 现在可以提取了
await staking.unstake(0);
```

## 测试完成后恢复

测试完成后，确保：

1. **不要提交** `StakingTestnet.sol` 到主分支（或标记为测试专用）
2. **恢复部署脚本** 使用 `Staking` 而不是 `StakingTestnet`
3. **主网部署时** 务必使用 `contracts/AE-Staking/src/mainnet/Staking.sol`

## 注意事项

### 1. 复利计算的准确性

测试版本的复利计算与主网完全一致，只是时间单位不同：

- **主网**: `stakingDuration / 1 days` = 质押天数
- **测试**: `stakingDuration / 30 seconds` = 质押"天"数（实际是30秒的倍数）

### 2. APY 利率不需要修改

APY 利率（如 1.006）表示的是"每个时间单位"的复利率，不需要修改。测试版本中：
- 每30秒应用一次 0.6% 的复利
- 7个周期（210秒）后的收益与主网7天的收益计算方式相同

### 3. 其他时间相关常量

合约中还有一个时间常量不需要修改：

```solidity
uint256 internal constant NETWORK_CHECK_INTERVAL = 1 minutes;
```

这个是网络活动检查间隔，1分钟对测试来说已经足够短，不需要修改。

### 4. EOA 检查

测试版本禁用了 EOA 检查（`shouldCheckEOA() returns false`），允许合约调用，方便自动化测试。主网必须启用此检查。

## 快速参考

### 创建测试合约的最小改动

只需要修改这3个函数：

```solidity
// 1. 质押周期：天数 * 30秒
function getStakePeriod7D() internal pure override returns (uint256) {
    return 7 * 30; // 210秒
}

// 2. 复利时间单位：30秒
function getCompoundTimeUnit() internal pure override returns (uint256) {
    return 30; // 30秒代表1天
}

// 3. EOA检查：禁用（可选）
function shouldCheckEOA() internal pure override returns (bool) {
    return false; // 允许合约调用
}
```

### 时间换算公式

```
测试时间（秒） = 主网天数 × 30
实际等待（分钟） = 测试时间 / 60
```

## 总结

通过创建 `StakingTestnet` 合约，我们可以：

1. ✅ 将 7天质押缩短到 3.5分钟
2. ✅ 保持复利计算逻辑完全一致
3. ✅ 不影响主网合约代码
4. ✅ 测试完成后轻松恢复
5. ✅ 支持自动化测试（禁用EOA检查）

这种方法比直接修改主网合约更安全，避免了测试配置意外部署到生产环境的风险。
