# AE-Staking 本地测试时间配置指南

## 概述

在本地测试 AE-Staking 合约时，质押周期太长（7天、30天等）不利于快速测试。本指南说明如何临时修改代码加速测试，以及测试完成后如何恢复。

## 需要修改的文件

**文件路径**: [contracts/AE-Staking/src/mainnet/Staking.sol](../contracts/AE-Staking/src/mainnet/Staking.sol)

只需要修改这一个文件中的时间相关函数。

---

## 测试时的修改

### 修改 1: 质押周期（改为秒）

**位置**: Staking.sol 第 48-67 行

```solidity
// 修改前（主网配置 - 天）
function getStakePeriod7D() internal pure override returns (uint256) {
    return 7 days;
}

function getStakePeriod30D() internal pure override returns (uint256) {
    return 30 days;
}

function getStakePeriod90D() internal pure override returns (uint256) {
    return 90 days;
}

function getStakePeriod180D() internal pure override returns (uint256) {
    return 180 days;
}

function getStakePeriod365D() internal pure override returns (uint256) {
    return 365 days;
}
```

**改为（测试配置 - 秒）**:

```solidity
// 修改后（测试配置 - 秒）
// 建议: 1天 = 30秒
function getStakePeriod7D() internal pure override returns (uint256) {
    return 7 * 30;  // 210秒 = 3.5分钟
}

function getStakePeriod30D() internal pure override returns (uint256) {
    return 30 * 30;  // 900秒 = 15分钟
}

function getStakePeriod90D() internal pure override returns (uint256) {
    return 90 * 30;  // 2700秒 = 45分钟
}

function getStakePeriod180D() internal pure override returns (uint256) {
    return 180 * 30;  // 5400秒 = 90分钟
}

function getStakePeriod365D() internal pure override returns (uint256) {
    return 365 * 30;  // 10950秒 = 182.5分钟
}
```

### 修改 2: 复利时间单位（改为秒）

**位置**: Staking.sol 第 111-114 行

```solidity
// 修改前（主网配置）
function getCompoundTimeUnit() internal pure override returns (uint256) {
    return 1 days;
}
```

**改为（测试配置）**:

```solidity
// 修改后（测试配置）
function getCompoundTimeUnit() internal pure override returns (uint256) {
    return 30;  // 30秒代表1天，用于复利计算
}
```

### 修改 3: EOA 检查（可选，方便测试）

**位置**: Staking.sol 第 106-109 行

```solidity
// 修改前（主网配置 - 启用）
function shouldCheckEOA() internal pure override returns (bool) {
    return true;
}
```

**改为（测试配置 - 禁用）**:

```solidity
// 修改后（测试配置 - 禁用，允许合约调用）
function shouldCheckEOA() internal pure override returns (bool) {
    return false;
}
```

## 测试流程

```bash

# 2. 编译合约
npx hardhat compile

# 3. 启动本地测试网络
npx hardhat node --hostname 0.0.0.0 --port 8545 --fork https://rpc.tornadoeth.cash/bsc --fork-block-number 64340000

# 4. 部署（在另一个终端）
npx hardhat run scripts/deploySYI.js --network localhost

# 5. 运行测试
npx hardhat run scripts/testSYIStaking.js --network localhost

# 6. 测试质押
# - 质押 7天期：等待 210秒（3.5分钟）后可提取
# - 或使用 hardhat 时间快进功能
```

## 注意事项

### ⚠️ 重要警告

1. **测试配置绝对不能部署到主网**
2. **提交代码前务必检查是否已恢复**
3. **建议使用 git stash 或创建测试分支**

### 安全建议

```bash
# 方法 1: 使用 git stash（推荐）
# 修改前
git stash  # 保存当前工作

# 修改并测试
# ... 修改 Staking.sol 并测试 ...

# 测试完成后恢复
git stash pop  # 恢复之前的状态

# 方法 2: 创建测试分支
git checkout -b test-staking-time
# ... 修改并测试 ...
git checkout main  # 切回主分支，修改不会带过来
```

### 为什么不需要修改 APY 利率？

APY 利率（如 1.006）表示"每个时间单位"的复利率：
- 主网: 每天应用 0.6% 复利
- 测试: 每 30秒 应用 0.6% 复利

计算逻辑完全相同，只是时间单位不同，所以不需要修改利率值。

## 使用 Hardhat 时间快进（可选）

如果不想真实等待，可以在测试脚本中使用时间快进：

```javascript
const { time } = require("@nomicfoundation/hardhat-network-helpers");

// 质押
await staking.stake(amount, 0); // 0 = 7天期

// 快进 210秒
await time.increase(210);

// 现在可以提取了
await staking.unstake(0);
```

这样连 3.5 分钟都不用等，瞬间完成测试。
