# 利润税分配修改方案

## 利润税总比例

卖出盈利部分的 **25%** 作为利润税（`PROFIT_TAX_RATE = 2500 / 10000`）。

## 修改目标

移除利润税中的「营销基金」和「销毁」两项，将「周 Top15 奖励」从 15% 调整为 40%，「流动性增强」从 15% 调整为 60%。

## 当前分配 vs 修改后分配

| 去向 | 当前比例 | 修改后比例 | 变化 | 说明 |
|------|---------|-----------|------|------|
| 周 Top15 奖励 | 15% | 40% | +25% | 每周交易排名前15名奖励 |
| 流动性增强 | 15% | 60% | +45% | 自动买入 AE 并添加流动性，LP 烧毁 |
| 营销基金 | 10% | - | 移除 | |
| 销毁 | 60% | - | 移除 | |
| **合计** | **100%** | **100%** | | |

## 涉及修改的文件

### 1. 合约代码：AEBase.sol

文件路径：`contracts/AE/src/abstract/AEBase.sol`

#### 修改点 A：删除利润税中的营销基金分配（第 862-869 行）

删除以下代码：

```solidity
// 10% → 买入 AE 后发送到 marketingFundAddress
uint256 marketingShare = (usdtAmountFromProfitTax * 10) / 100;
if (marketingShare > 0) {
    uint256 aeAmount = _swapUSDTForTokens(marketingShare);
    if (aeAmount > 0 && marketingFundAddress != address(0)) {
        super._update(address(this), marketingFundAddress, aeAmount);
    }
}
```

#### 修改点 B：删除利润税中的销毁分配（第 871-879 行）

删除以下代码：

```solidity
// 60% → 买入 AE 后销毁
uint256 burnShare = (usdtAmountFromProfitTax * 60) / 100;
if (burnShare > 0) {
    uint256 aeAmount = _swapUSDTForTokens(burnShare);
    if (aeAmount > 0) {
        super._update(address(this), DEAD_ADDRESS, aeAmount);
        emit TokensBurned(aeAmount);
    }
}
```

#### 修改点 C：调整流动性增强比例（第 852 行）

```solidity
// 修改前
uint256 liquidityShare = (usdtAmountFromProfitTax * 15) / 100;

// 修改后
uint256 liquidityShare = (usdtAmountFromProfitTax * 60) / 100;
```

#### 修改点 D：调整周 Top15 奖励比例（第 857 行）

```solidity
// 修改前
uint256 weeklyRewardShare = (usdtAmountFromProfitTax * 15) / 100;

// 修改后
uint256 weeklyRewardShare = (usdtAmountFromProfitTax * 40) / 100;
```

#### 修改点 E：清理 profitTaxToMarketing 赋值（第 881 行）

删除或置零：

```solidity
// 修改前
profitTaxToMarketing = marketingShare;

// 修改后（删除此行，因为 marketingShare 变量已不存在）
```

#### 需要确认：marketingFundAddress 是否还需要保留？

`marketingFundAddress` 在合约中还有以下用途：
- **固定卖出税 1.5%**（第 800 行）：卖出时 1.5% AE 直接发送到 `marketingFundAddress`
- **多处 fallback 逻辑**（第 1030-1039、1421-1423、1448-1450 行）：swap 或添加流动性失败时，USDT 会转到 `marketingFundAddress` 作为兜底

因此 `marketingFundAddress` 状态变量和构造函数参数需要保留，不能删除。

### 2. 产品文档

文件路径：`notes/AetherDAO产品文档.md`（第 46-51 行）

将利润税分配表更新为修改后的版本。

### 3. 部署脚本和配置

`scripts/deployAE.js` 和 `ae-deployment-config.json` 中的 `marketingFundAddress` 参数保留不变（固定卖出税仍需使用）。
