# AE-Staking 合约测试方案

## 一、测试范围概述

本文档覆盖 `contracts/AE-Staking` 合约的全部核心功能测试，包括质押、赎回、利息提取、推荐人体系、团队奖励分配、管理员功能及边界条件。

---

## 二、测试模块清单

### 模块 1：质押功能 (stake)

| 编号 | 测试项 | 说明 |
|------|--------|------|
| 1.1 | 基本质押 | 用户质押 100 USDT（最低额度），验证余额变化、事件触发 |
| 1.2 | 最大单次质押 | 质押 1000 USDT（单次上限），验证成功 |
| 1.3 | 低于最低额度 | 质押 99 USDT，应 revert |
| 1.4 | 超过单次上限 | 质押 1001 USDT，应 revert |
| 1.5 | 用户总质押上限 | 累计质押超过 10,000 USDT，应 revert |
| 1.6 | 5 种期限质押 | 分别测试 7/30/90/180/365 天期限，验证利率正确 |
| 1.7 | 7 天期限仅限一次 | 第一次 7 天质押成功，第二次应 revert |
| 1.8 | 无效期限索引 | stakeIndex > 4，应 revert |
| 1.9 | 未绑定推荐人不能质押 | 用户未绑定推荐人时质押，应 revert |
| 1.10 | 流动性添加验证 | 质押后验证 50% USDT 兑换 AE + 50% 添加流动性 |
| 1.11 | LP Token 烧毁 | 验证添加流动性后 LP 被发送到 burn 地址 |
| 1.12 | 多次质押累计 | 同一用户多次质押，验证 totalStaked 累计正确 |
| 1.13 | 动态最大质押额 | 验证 maxStakeAmount = min(1000, 池子1% - 近期流入) |
| 1.14 | USDX 授权不足 | 用户未 approve 足够 USDX，应 revert |
| 1.15 | Staked 事件验证 | 验证事件参数：user, amount, timestamp, index, stakeTime |
