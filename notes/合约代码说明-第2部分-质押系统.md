#### 核心函数详解

##### `stake(amount, stakeIndex)` — 质押

```
stake(amount, stakeIndex)
├── 权限检查
│   ├── onlyEOA（主网禁止合约调用）
│   └── 金额校验（≥100, ≤1000, 总计≤10000 USDT）
├── 7 天质押特殊处理（仅允许使用一次）
├── 用户转入 USDT 到合约
├── 50% USDT → 兑换 AE 代币
├── AE + USDT → 添加 Uniswap 流动性
├── LP Token 烧毁（发送到 dead 地址）
├── 创建质押记录 Record
├── 更新用户余额 balances[user]
├── 更新团队 KPI（向上遍历推荐链）
└── 触发 Staked 事件
```

##### `unstake(recordIndex)` — 赎回

```
unstake(recordIndex)
├── 校验质押记录存在且有效
├── 计算复利收益 _calculateStakeReward()
│   └── principal × (1 + dailyRate)^days
├── 扣除已提取利息 withdrawnInterest
├── 将收益 AE → USDT（通过 Uniswap）
├── 手续费分配
│   ├── 5% → 教育基金地址（educationFundAddress）
│   ├── ≤35% → 团队奖励（_distributeTeamReward）
│   └── 1% → 赎回手续费（feeRecipient）
├── 剩余 USDT → 转给用户
├── 标记记录为已赎回
├── 更新余额和总供应量
├── 记录提取历史 WithdrawalRecord
└── 触发 RewardPaid + WithdrawalCompleted 事件
```

##### `withdrawInterest(recordIndex)` — 提前提取利息

```
withdrawInterest(recordIndex)
├── 校验质押记录存在且活跃
├── 计算当前累计利息
├── 减去已提取利息 → 可提取利息
├── 将利息 AE → USDT
├── 手续费分配（同 unstake）
│   ├── 5% → 教育基金
│   ├── ≤35% → 团队奖励
│   └── 1% → 赎回手续费
├── 剩余 → 转给用户
├── 累加 withdrawnInterest 记录
├── 本金继续生息
└── 触发 InterestWithdrawn 事件
```

##### `_calculateStakeReward()` — 复利计算

使用 PRBMath 的 UD60x18 定点数库实现精确复利：

```
reward = principal × (1 + dailyRate) ^ compoundingPeriods

其中：
- dailyRate = 对应质押期的日利率
- compoundingPeriods = min(已过天数, 质押期天数)
- 使用 UD60x18.pow() 精确计算幂运算
```

#### 推荐人系统

##### `lockReferral(referrer)` — 绑定推荐人

```
lockReferral(referrer)
├── 检查未绑定过
├── 检查不能自我推荐
├── 检查推荐人已绑定（或是 rootAddress）
├── 检查不会形成循环引用
├── 记录推荐关系
├── 将绑定者加入推荐人的 children 列表
├── 同步现有投资到推荐链 KPI
└── 触发 ReferralBound 事件
```

##### `_distributeTeamReward()` — 团队奖励分配

采用"严格差额制"分配：

```
_distributeTeamReward(referralChain, interest)
├── interest × 35% = 团队奖励池
├── 遍历推荐链（从直接推荐人向上）
├── 找到链中最高等级者
├── 按差额计算每层奖励
│   例如：V5(19%) 在 V3(11%) 上面
│   → V5 拿 19%-11% = 8% 的差额部分
│   → V3 拿 11%-0% = 11% 的部分
├── 未分配部分 → rootAddress
└── 触发 StrictDifferentialRewardPaid 事件
```

##### 等级判定

```
用户等级 = min(团队KPI等级, 个人质押等级)

团队 KPI 等级：由 teamTotalInvestValue 决定
  → 所有下级的质押总额
个人质押等级：由用户当前活跃质押总额决定
  → 必须满足对应等级的最低个人质押
```

#### 滑点保护

```
_calculateMinimumOutput(amount, reserveIn, reserveOut)
├── 基础滑点：15%
├── 计算价格影响
│   └── priceImpact = amount / reserveIn
├── 动态调整滑点（最大 20%）
├── 扣除 Uniswap 手续费（0.3%）
└── 返回最低接受输出量
```

### 3.3 接口文件

#### IStaking.sol

定义质押合约的完整接口，包括：
- 数据结构：`Record`, `RecordTT`, `TeamTier`, `WithdrawalRecord`
- 质押操作：`stake()`, `unstake()`, `withdrawInterest()`
- 推荐人操作：`lockReferral()`, `getReferral()`, `getReferrals()`
- 查询函数：`getUserInfo()`, `getTeamKpi()`, `isPreacher()`

#### IAE.sol

AE 代币接口（继承 IERC20），staking 合约调用时使用：
- `recycle(amount)` — 回收代币
- `getUniswapV2Pair()` — 获取交易对地址
- `getUSDTReserve()` — 获取 USDT 储备量
- `triggerFundRelayDistribution()` — 触发资金中转分配
- `triggerFeeProcessing()` — 触发手续费处理
