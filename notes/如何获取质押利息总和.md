# 如何获取质押利息总和（扣费后净到账）

## 结论

合约中没有一个函数能直接返回"扣费后净利息累计"。但可以通过两个现有函数**精确计算**：

```
净利息累计（已领取） = stakingReward - Σ principalAmount
```

即：`getUserRewardSummary` 的 stakingReward 减去 `getWithdrawalHistory` 中所有本金之和。

---

## 推导过程

### stakingReward 是什么

`stakingReward = totalClaimedStakingReward[user]`，它在两个地方累加：

- `unstake()` 第 351 行：`+= userPayout`（本金 + 净利息，扣完所有费后）
- `withdrawInterest()` 第 440 行：`+= userPayout`（纯净利息，扣完所有费后）

所以：

```
stakingReward = Σ unstake 到账额 + Σ withdrawInterest 到账额
             = Σ (本金 + 净利息) + Σ (净利息)
             = Σ 本金 + Σ 所有净利息
```

### 减去本金就是净利息

```
Σ 所有净利息 = stakingReward - Σ 本金
```

本金在哪里？每次 `unstake` 都会写入 `WithdrawalRecord.principalAmount`。而 `withdrawInterest` 不涉及本金（本金不动）。

所以：

```
净利息累计（已领取） = stakingReward - Σ WithdrawalRecord.principalAmount
```

## 前端代码

```javascript
/**
 * 获取用户已领取的质押净利息累计（扣费后实际到账）
 * 不含活跃订单的未领取利息
 */
async function getClaimedNetInterest(staking, userAddress) {
    const [stakingReward] = await staking.getUserRewardSummary(userAddress);
    const history = await staking.getWithdrawalHistory(userAddress);

    let totalPrincipalReturned = 0n;
    for (const record of history) {
        totalPrincipalReturned += record.principalAmount;
    }

    return stakingReward - totalPrincipalReturned;
}
```

### 返回值说明

| 属性 | 说明 |
|------|------|
| 含义 | 用户从质押系统累计赚到的净利息（扣除教育基金+团队奖励+赎回费后） |
| 是否包含本金 | **否** — 已减去 |
| 是否已扣费 | **是** — 这是实际到账金额 |
| 是否包含活跃订单未领取利息 | **否** — 只含已通过 unstake/withdrawInterest 到账的部分 |

### 验证举例

用户质押 1000 USDX，30 天到期，利息 300 USDX，中间第 15 天提取过一次利息。

| 操作 | userPayout（到账） | principalAmount |
|------|-------------------|----------------|
| 第 15 天 withdrawInterest | 79.8 USDX | 无（不记录） |
| 第 30 天 unstake | 1041.2 USDX | 1000 USDX |

```
stakingReward = 79.8 + 1041.2 = 1121 USDX
Σ principalAmount = 1000 USDX
净利息 = 1121 - 1000 = 121 USDX  ← 扣完所有费后的纯利润
```

## 如果还要加上活跃订单的"预期净利息"

上面的计算只包含已到账的部分。如果还想加上活跃订单当前累积的、尚未领取的利息，需要额外计算，但这部分只有**毛利息**（扣费前），无法精确得到净值：

```javascript
/**
 * 获取完整利息视图（已领取净额 + 活跃订单毛利息估算）
 */
async function getFullInterestView(staking, userAddress) {
    // ① 已领取净利息（精确）
    const claimedNet = await getClaimedNetInterest(staking, userAddress);

    // ② 活跃订单未领取的毛利息
    const orders = await staking.getUserStakeRecords(userAddress);
    let pendingGross = 0n;
    for (const order of orders) {
        if (!order.status) {
            const pending = order.earnedInterest - order.withdrawnInterestAmount;
            if (pending > 0n) {
                pendingGross += pending;
            }
        }
    }

    return {
        claimedNetInterest: claimedNet,        // 已领取净利息（精确，扣费后）
        pendingGrossInterest: pendingGross,     // 未领取毛利息（扣费前）
    };
}
```

**为什么活跃订单只能给毛利息？**

因为扣费金额取决于领取时的实际情况：
- 团队奖励比例（≤35%）取决于推荐链上各人的实时等级
- AE/USDX 兑换率影响实际换到的 USDX 数量
- 这些在领取前都是不确定的

如果前端需要估算，可以用固定比例：

```javascript
// 估算净值 ≈ 毛利息 × 57%
// 扣费结构：教育基金 5% + 团队奖励 35% = 剩 60%，再扣赎回费 5% = 60% × 95% ≈ 57%
const pendingNetEstimate = pendingGross * 57n / 100n;
```

## 是否需要新增合约函数

用现有接口（`getUserRewardSummary` + `getWithdrawalHistory`）已经可以精确算出已领取的净利息。

但如果觉得前端遍历 `getWithdrawalHistory` 不够方便（记录多时 gas 高），可以考虑在合约中新增一个状态变量：

```solidity
// 方案：新增一个 mapping 专门记录已退还本金累计
mapping(address => uint256) public totalPrincipalReturned;

// 在 unstake() 中累加：
totalPrincipalReturned[msg.sender] += principalAmount;
```

这样前端只需要：
```javascript
const [stakingReward] = await staking.getUserRewardSummary(userAddress);
const principalReturned = await staking.totalPrincipalReturned(userAddress);
const netInterest = stakingReward - principalReturned;
```

一次调用，无需遍历历史记录。

## 各种"利息"值对照表

| 需求 | 怎么拿 | 扣费 | 含活跃订单 |
|------|-------|------|-----------|
| 已领取净利息（精确） | `stakingReward - Σ principalAmount` | 已扣费 | 否 |
| 已领取毛利息 | `Σ WithdrawalRecord.interestEarned + Σ withdrawnInterestAmount` | 未扣费 | 否 |
| 活跃订单毛利息 | `Σ (earnedInterest - withdrawnInterestAmount)` 仅活跃订单 | 未扣费 | 仅活跃 |
| 全部毛利息（含活跃） | 上面两项之和 | 未扣费 | 是 |
| 全部净利息（含活跃） | 已领取净利息 + 活跃订单毛利息 × 57%（估算） | 混合 | 是（估算） |
