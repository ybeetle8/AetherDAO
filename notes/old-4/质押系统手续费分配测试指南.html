AetherDAO 质押系统 — 手续费分配测试指南

本文以 1000 USDC 质押、30天期 为例，详细说明质押、领息、解质押各环节的手续费计算与分配流程。供测试人员对照验证。

二、场景设定

  • 用户 Alice 质押 1000 USDX，选择 30天档（Index 1，日利率 0.9%）
  • Alice 的推荐链：Alice → Bob(V2) → Charlie(V1)
    • Bob 的有效等级 = V2（团队KPI等级和个人质押等级的较小值）
    • Charlie 的有效等级 = V1

三、质押时（stake）：手续费分配

3.1 流程概述

用户调用 stake(1000, 1)，合约执行 _swapAndAddLiquidity(1000 USDX)：

  1. 从用户钱包转入 1000 USDX 到合约
  2. 将 1000 USDX 一分为二：
    • 500 USDX 用于在 DEX 上 swap 为 AE 代币
    • 500 USDX 保留，用于添加流动性

3.2 Swap 环节的手续费（AE 代币层面）

swap 500 USDX → AE 时，AE 代币合约收取买入税：

费用项 费率 金额（从 AE 产出中扣） 去向
燃烧费 0.5% swap 产出的 0.5% AE 被销毁 销毁（减少供应）
流动性费 2.5% swap 产出的 2.5% AE 归入 LP LP 池积累
合计 3.0% — —

注意：这 3% 是 AE 代币合约的买入税，扣的是 AE 产出量，不是 USDX。用户投入的 1000 USDX 全部进入协议（一半 swap、一半加 LP），但拿到的 AE 少了 3%。

3.3 添加流动性

  • 将 swap 得到的 AE + 剩余 500 USDX 组成 LP
  • LP 代币发送到 address(0)（永久锁定）

3.4 质押记录

  • 合约为 Alice 铸造 sAE 代币，记录本金 = 1000 USDX
  • 利息按 1000 USDX 本金开始复利计算

3.5 测试验证点

  • 确认 Alice 钱包减少 1000 USDX
  • 确认合约调用 router 进行 swap（约 500 USDX → AE）
  • 确认 AE 代币的 3% 买入税被正确收取（燃烧 + 流动性）
  • 确认 LP 代币发送到 address(0)
  • 确认 Alice 的质押记录：amount=1000, stakeIndex=1, status=false
  • 确认 Alice 的 sAE 余额增加
  • 如果是 Index 0（7天档），确认 hasUsed7DayStake 被标记为 true

四、利息计算

4.1 复利公式 

当前价值 = 本金 × (日利率)^(已过天数)
利息 = 当前价值 - 本金

4.2 以 1000 USDX、30天档为例

日利率系数 = 1.009（即每天增长 0.9%）

天数 当前价值 (USDX) 累计利息 (USDX)
1 1000 × 1.009^1 = 1,009.00 9.00
7 1000 × 1.009^7 ≈ 1,064.73 64.73
15 1000 × 1.009^15 ≈ 1,143.96 143.96
30（到期） 1000 × 1.009^30 ≈ 1,308.65 308.65

到期时：本金 1000 + 利息 ≈ 308.65 = 总价值 ≈ 1308.65 USDX

五、提前领取利息（withdrawInterest）：手续费分配

可在锁仓期内多次领取已产生的利息，本金继续质押产生收益。

5.1 场景：第 15 天领取利息

假设第 15 天，累计利息 ≈ 143.96 USDX（之前未领取过）。

第一步：swap AE → USDX 兑现利息

合约从 AE/USDX 池中 swap 出约 143.96 USDX（实际受滑点影响）。

假设实际 swap 得到 usdxReceived = 140 USDX（含滑点损耗）。

第二步：从 usdxReceived 中扣除教育基金 + 团队奖励

费用项 计算 金额 去向
教育基金 140 × 5% 7.00 USDX 教育基金地址
团队奖励池 140 × 35% 49.00 USDX 推荐链分配（见下）
扣费后余额 140 - 7 - 49 84.00 USDX 准备发给用户

第三步：团队奖励分配（差级制）

推荐链：Alice → Bob(V2, 7%) → Charlie(V1, 3%)

从 Alice 往上遍历：

  1. Charlie（V1）：第一个遇到的 V1 等级，奖励率 = 3% - 0% = 3%
    • Charlie 获得：140 × 3% = 4.20 USDX
  2. Bob（V2）：第一个遇到的 V2 等级，奖励率 = 7% - 3% = 4%（差级）
    • Bob 获得：140 × 4% = 5.60 USDX
  3. 实际分出：4.20 + 5.60 = 9.80 USDX
  4. 剩余：49.00 - 9.80 = 39.20 USDX → 转给 rootAddress（市场营销）

第四步：赎回手续费

费用项 计算 金额 去向
赎回手续费 84.00 × 500/10000 = 84.00 × 5% 4.20 USDX feeRecipient 地址

注意：赎回手续费是额外从 AE 池 swap 出来支付的，不从用户到手金额中扣。

第五步：用户到手

项目 金额
用户实际到手 84.00 USDX

5.2 领息费用汇总

去向 金额 占 swap 产出比例
教育基金 7.00 5%
Charlie（V1 推荐人） 4.20 3%
Bob（V2 推荐人） 5.60 4%（差级）
rootAddress（市场营销） 39.20 28%（35%-7%的剩余）
赎回手续费（feeRecipient） 4.20 用户到手金额的 5%（额外 swap）
用户到手 84.00 60%

5.3 测试验证点

  • 确认利息计算正确（复利公式）
  • 确认 withdrawnInterest[Alice][stakeIndex] 被正确更新
  • 确认教育基金地址收到 usdxReceived × 5%
  • 确认团队奖励按差级制分配给推荐链
  • 确认剩余团队奖励转给 rootAddress
  • 确认赎回手续费转给 feeRecipient
  • 确认用户到手 = usdxReceived - 教育基金 - 团队奖励
  • 确认本金仍在质押中，status 仍为 false
  • 确认可以多次领取，但不能超过已产生的利息

六、到期解质押（unstake）：手续费分配

6.1 场景：第 30 天到期后解质押

到期时总价值 ≈ 1308.65 USDX（本金 1000 + 利息 308.65）。

假设之前在第 15 天已经领过一次利息。那么 unstake 时的处理：

unstake 是返还本金+全部利息的操作，利息部分指的是总复利收益。

第一步：销毁质押记录，计算总奖励

合约计算 calculatedReward = 1000 × 1.009^30 ≈ 1308.65 USDX（完整复利值）

第二步：swap AE → USDX

将 calculatedReward 对应的 AE 代币 swap 为 USDX。

假设实际 swap 得到 usdxReceived = 1280 USDX（含滑点损耗）。

第三步：计算利息部分

interestEarned = usdxReceived - principalAmount = 1280 - 1000 = 280 USDX

关键：教育基金和团队奖励只从利息部分（280 USDX）中计算，不动本金。

第四步：从利息中扣除教育基金 + 团队奖励

费用项 计算 金额 去向
教育基金 280 × 5% 14.00 USDX 教育基金地址
团队奖励池 280 × 35% 98.00 USDX 推荐链分配

第五步：团队奖励分配（差级制）

同上，推荐链 Alice → Bob(V2) → Charlie(V1)：

  1. Charlie（V1）：奖励率 3%，获得 280 × 3% = 8.40 USDX
  2. Bob（V2）：差级奖励率 7% - 3% = 4%，获得 280 × 4% = 11.20 USDX
  3. 实际分出：8.40 + 11.20 = 19.60 USDX
  4. 剩余：98.00 - 19.60 = 78.40 USDX → rootAddress

第六步：计算用户到手（扣费后）

userPayout = usdxReceived - 教育基金 - 团队奖励
           = 1280 - 14.00 - 98.00
           = 1168.00 USDX

第七步：赎回手续费

赎回手续费 = userPayout × 500 / 10000 = 1168.00 × 5% = 58.40 USDX

同样，赎回手续费是额外从 AE 池 swap 出来发给 feeRecipient 的，不从 userPayout 中扣。

第八步：用户到手

用户实际到手 = 1168.00 USDX（包含本金 + 扣费后利息）

6.2 解质押费用汇总

去向 金额 说明
教育基金 14.00 利息的 5%
Charlie（V1） 8.40 利息的 3%
Bob（V2） 11.20 利息的 4%（差级）
rootAddress 78.40 利息的 28%（团队奖励剩余）
赎回手续费（feeRecipient） 58.40 userPayout 的 5%（额外 swap）
用户到手 1168.00 本金 + 利息 - 教育基金 - 团队奖励

6.3 测试验证点

  • 确认必须在锁仓期满后才能 unstake（否则 revert StakingPeriodNotMet）
  • 确认复利计算正确：1000 × 1.009^30
  • 确认 interestEarned = usdxReceived - principalAmount
  • 确认教育基金 = interestEarned × 5%
  • 确认团队奖励 = interestEarned × 35%
  • 确认团队奖励按差级制分配
  • 确认 userPayout = usdxReceived - 教育基金 - 团队奖励
  • 确认赎回手续费 = userPayout × 5%，转给 feeRecipient
  • 确认用户收到 userPayout
  • 确认 AE 代币被 recycle
  • 确认质押记录 status 变为 true
  • 确认 sAE 余额减少
  • 确认 teamTotalInvestValue 被正确更新（减少本金）

七、团队奖励差级制详解

7.1 等级体系

用户的有效等级 = min(团队KPI等级, 个人质押等级)

团队 KPI 等级门槛：

V2 10,000 USDX 7%
V3 30,000 USDX 11%
V4 100,000 USDX 15%
V5 300,000 USDX 19%
V6 1,000,000 USDX 23%
V7 3,000,000 USDX 27%
V8 10,000,000 USDX 31%
V9 30,000,000 USDX 35%

个人质押等级门槛：

等级 个人质押额门槛
V1 100 USDX

7.2 差级分配示例

假设利息 = 100 USDX，团队奖励池 = 100 × 35% = 35 USDX

推荐链（从用户往上）：Alice → D(V1) → E(V0) → F(V3) → G(V2) → H(V5)

遍历分配过程：

顺序 成员 等级 该等级奖励率 已累计率 差级奖励率 获得金额
1 D V1 3% 0% 3% 100 × 3% = 3.00
2 E V0 — 3% 跳过（V0 无奖励） 0
3 F V3 11% 3% 11%-3% = 8% 100 × 8% = 8.00
4 G V2 7% 11% 跳过（7% < 已累计11%） 0
5 H V5 19% 11% 19%-11% = 8% 100 × 8% = 8.00
  • 实际分出：3.00 + 8.00 + 8.00 = 19.00 USDX
  • 剩余：35.00 - 19.00 = 16.00 USDX → rootAddress

关键规则：

  1. 每个等级只有第一个遇到的成员获得奖励
  2. 奖励率 = 当前等级费率 - 已累计费率（差级）
  3. 如果当前等级费率 ≤ 已累计费率，该成员不获得奖励
  4. 未分配完的部分转给 rootAddress

7.3 测试验证点

  • 确认 V0 等级成员不获得奖励
  • 确认同等级只有第一个成员获得奖励（后续同等级被跳过）
  • 确认低于已累计费率的成员不获得奖励（如上例 G）
  • 确认无推荐链时，全部 35% 转给 rootAddress
  • 确认差级计算正确

八、特殊场景测试

8.1 无推荐人的情况

如果用户没有推荐链（referralChain 为空）：

  • 教育基金 5% → 教育基金地址
  • 团队奖励 35% → 全部转给 rootAddress
  • 赎回手续费 5% → feeRecipient
  • 用户到手 = usdxReceived × 60%

8.2 多次领息后再解质押

  • 第 10 天领息一次，第 20 天领息一次，第 30 天解质押
  • withdrawInterest 记录已领取的利息
  • 但 unstake 时是独立计算的：unstake 返回的是完整的 calculatedReward（本金+全部复利），不扣除已领取的利息
  • 已领利息通过 withdrawnInterest mapping 追踪，但不影响 unstake 的计算

测试重点：确认 unstake 的 calculatedReward 是完整复利值，验证系统资金是否充足覆盖。

8.3 到期前尝试解质押

  • 调用 unstake() 应 revert，错误码 StakingPeriodNotMet
  • 但可以调用 withdrawInterest() 领取利息

8.4 7天档限制

  • 第一次质押 Index 0（7天档）：成功
  • 第二次质押 Index 0：revert "7-day stake can only be used once"
  • Owner 可以调用 reset7DayStakeUsage(user) 重置

8.5 质押金额限制

  • 低于 100 USDX：revert BelowMinStakeAmount
  • 超过 maxStakeAmount()（动态，受池子 1% 限制）：revert ExceedsMaxStakeAmount
  • 用户总质押超过 10,000 USDX：revert ExceedsUserTotalStakeLimit
