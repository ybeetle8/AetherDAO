# 为什么没收到交易费

## 简短回答

质押/解质押操作**不收交易税**，这是设计预期。交易税只对**普通用户通过 DEX 直接买卖 AE** 时收取。

## 两套独立的费用体系

```
┌─────────────────────────────────────────────────┐
│  AE 交易税（DEX 买卖时收取）                       │
│                                                   │
│  买入税 3%:  2% → 节点奖励  /  1% → 社区奖励       │
│  卖出税 3%:  1.5% → 营销基金  /  1.5% → 销毁       │
│                                                   │
│  ⚠ 质押合约在白名单中，免收此税                      │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│  质押费用（解质押时从利息中扣取）                     │
│                                                   │
│  教育基金:    利息的 5%   → educationFundAddress    │
│  团队奖励:    利息的 35%  → 推荐链上级               │
│  赎回手续费:  剩余利息的 5% → feeRecipient          │
│                                                   │
│  ✅ 这套费用正常收取中                              │
└─────────────────────────────────────────────────┘
```

## 为什么质押不收交易税

1. **技术原因**：解质押用的 `swapTokensForExactTokens` 不支持扣税，收税会直接 revert，解质押无法完成
2. **经济原因**：质押已收约 45% 利息作为费用，再叠加交易税会过度压缩用户收益

## 怎样才能收到交易税

需要**普通用户**（非白名单地址）通过 PancakeSwap **直接买卖 AE**：

```
普通用户用 USDX 在 DEX 买 AE → 触发 3% 买入税 → 节点奖励/社区奖励地址收到 AE
普通用户在 DEX 卖出 AE      → 触发 3% 卖出税 → 营销基金地址收到 AE
```

当前测试只做了质押/解质押，没有普通用户的 DEX 交易，所以交易税地址余额为 0。
