## 概述

AetherDAO 质押系统是一个基于 BSC 链的 DeFi 质押协议，用户使用 USDT 进行质押，通过 Uniswap V2 机制添加流动性，并获得复利收益。系统包含推荐奖励、团队奖励和好友奖励等多层次激励机制。

### 核心合约
- **StakingBase.sol**: 质押核心逻辑实现
- **Staking.sol**: 主网部署版本（继承 StakingBase）
- **IStaking.sol**: 质押接口定义

### 关键代币
- **USDT**: 质押本金代币
- **AE**: 项目代币，用于流动性和奖励兑换
- **sAE**: 质押凭证代币（不可转让）

## 质押流程分析

### 1. 质押入口函数

**函数**: `stake(uint160 _amount, uint8 _stakeIndex)`

**位置**: [StakingBase.sol:224](contracts/AE-Staking/src/abstract/StakingBase.sol#L224)

### 2. 质押前置条件

用户在质押前必须满足以下条件：

#### 2.1 绑定推荐关系
```solidity
// 必须先调用 lockReferral() 绑定推荐人
if (!isBindReferral(sender)) revert MustBindReferral();
```

#### 2.2 质押金额限制
- **最小质押**: 100 USDT (`MIN_STAKE_AMOUNT`)
- **单次最大**: 1000 USDT (`MAX_STAKE_LIMIT`)
- **用户总限额**: 10000 USDT (`MAX_USER_TOTAL_STAKE`)
- **动态限制**: 基于网络流入量和池子储备的 1%

#### 2.3 7天期特殊限制
```solidity
// 7天期质押只能使用一次
if (_stakeIndex == 0) {
    require(!hasUsed7DayStake[msg.sender], "7-day stake can only be used once");
    hasUsed7DayStake[msg.sender] = true;
}
```

### 3. 质押期限与收益率

| 质押期限 | stakeIndex | 日复利率 | 年化收益率(APY) |
|---------|-----------|---------|----------------|
| 7天     | 0         | 0.6%    | ~900%          |
| 30天    | 1         | 0.9%    | ~2,700%        |
| 90天    | 2         | 1.1%    | ~4,400%        |
| 180天   | 3         | 1.5%    | ~12,000%       |
| 365天   | 4         | 2.0%    | ~130,000%      |

**注意**: 这些是日复利收益率，实际收益按复利公式计算。

### 4. 资金流转过程

#### 4.1 用户转入 USDT
```solidity
IERC20(USDT).transferFrom(msg.sender, address(this), usdtAmount);
```

#### 4.2 资金分配（50/50 分割）
```solidity
uint256 usdtToSwap = usdtAmount / 2;  // 50% 用于购买 AE
uint256 remainingUsdt = usdtAmount - usdtToSwap;  // 50% 保留为 USDT
```

#### 4.3 购买 AE 代币
```solidity
// 通过 Uniswap V2 Router 将 50% USDT 兑换为 AE
ROUTER.swapExactTokensForTokensSupportingFeeOnTransferTokens(
    usdtToSwap,
    minAeTokensOut,  // 滑点保护
    swapPath,        // [USDT, AE]
    address(this),
    block.timestamp
);
```

**滑点保护机制**:
- 基础滑点容忍度: 15% (`BASE_SLIPPAGE_TOLERANCE = 1500`)
- 最大滑点容忍度: 20% (`MAX_SLIPPAGE_TOLERANCE = 2000`)
- 价格影响阈值: 2% (`PRICE_IMPACT_THRESHOLD = 200`)
- 考虑 AE 买入税: 3% (0.5% 销毁 + 2.5% 流动性)

#### 4.4 添加流动性
```solidity
ROUTER.addLiquidity(
    address(USDT),
    address(AE),
    remainingUsdt,      // 剩余的 50% USDT
    aeTokensReceived,   // 购买到的 AE
    0,                  // 不设置最小 USDT
    0,                  // 不设置最小 AE
    address(0),         // LP 代币销毁
    block.timestamp
);
```

**关键点**: LP 代币被发送到 `address(0)` 销毁，这意味着流动性被永久锁定。

### 5. 铸造质押凭证

#### 5.1 记录网络总供应量
```solidity
RecordTT memory tsy;
tsy.stakeTime = uint40(block.timestamp);
tsy.tamount = uint160(totalSupply);
t_supply.push(tsy);
```

#### 5.2 创建用户质押记录
```solidity
Record memory order;
order.stakeTime = uint40(block.timestamp);
order.amount = _amount;           // 质押本金
order.status = false;             // 未提取
order.stakeIndex = _stakeIndex;   // 质押期限索引
userStakeRecord[sender].push(order);
```

#### 5.3 更新团队投资值
```solidity
// 向上遍历推荐链，更新所有上级的团队业绩
_updateTeamInvestmentValues(sender, _amount, true);
```

#### 5.4 铸造 sAE 代币
```solidity
_update(address(0), sender, _amount);
// 这会增加:
// - balances[sender] += _amount
// - totalSupply += _amount
```

## 解质押流程分析

### 1. 解质押入口函数

**函数**: `unstake(uint256 stakeIndex)`

**位置**: [StakingBase.sol:239](contracts/AE-Staking/src/abstract/StakingBase.sol#L239)

### 2. 解质押前置条件

#### 2.1 时间锁定检查
```solidity
if (block.timestamp - stakeTime < getStakePeriod(user_record.stakeIndex))
    revert StakingPeriodNotMet();
```

#### 2.2 状态检查
```solidity
if (user_record.status) revert AlreadyWithdrawn();
```

### 3. 收益计算

#### 3.1 复利计算公式
```solidity
// 计算复利期数
uint256 compoundPeriods = stakingDuration / 1 days;

// 复利公式: 本金 × (1 + 日利率)^天数
UD60x18 compoundedAmount = principalAmount.mul(
    baseInterestRate.powu(compoundPeriods)
);
```

**示例计算**:
- 质押 1000 USDT，选择 30 天期（0.9% 日复利）
- 复利期数 = 30
- 最终价值 = 1000 × (1.009)^30 ≈ 1,309 USDT
- 收益 = 309 USDT

#### 3.2 收益上限
```solidity
// 收益计算不会超过质押期限
stakingDuration = _min40(
    stakingDuration,
    uint40(getStakePeriod(stakeRecord.stakeIndex))
);
```

### 4. AE 兑换 USDT

#### 4.1 计算所需 AE 数量
```solidity
// 使用 swapTokensForExactTokens 精确兑换
uint256 maxXFInput = _calculateMaxAEInput(calculatedReward, aeBalanceBefore);
```

**安全机制**:
- 最大使用 AE 余额的 50%
- 考虑池子储备，避免过大冲击
- 150% 滑点保护

#### 4.2 执行兑换
```solidity
ROUTER.swapTokensForExactTokens(
    calculatedReward,  // 精确需要的 USDT 数量
    maxXFInput,        // 最大愿意支付的 AE 数量
    swapPath,          // [AE, USDT]
    address(this),
    block.timestamp
);
```

#### 4.3 回收 AE 代币
```solidity
AE.recycle(aeTokensUsed);  // 将使用的 AE 发送到回收地址
```

## 资金分配机制

### 1. 收益分配概览

解质押时，用户获得的 USDT 收益按以下顺序分配：

```
总收益 (usdtReceived)
├── 本金 (principalAmount)
└── 利息 (interestEarned = usdtReceived - principalAmount)
    ├── 好友奖励 (5%)
    ├── 团队奖励 (35%)
    ├── 赎回手续费 (1%)
    └── 用户实际收益 (剩余部分)
```

### 2. 好友奖励 (5%)

**函数**: `_distributeFriendReward()`

**位置**: [StakingBase.sol:1021](contracts/AE-Staking/src/abstract/StakingBase.sol#L1021)

```solidity
fee = (interestEarned * 5) / 100;  // 5% 的利息

address friend = getFriend(user);
if (friend != address(0)) {
    IERC20(USDT).transfer(friend, fee);
} else {
    IERC20(USDT).transfer(rootAddress, fee);  // 无好友则给根地址
}
```

**特点**:
- 用户可通过 `lockFriend()` 绑定一个好友地址
- 好友直接获得用户利息的 5%
- 如果未绑定好友，奖励归项目方

### 3. 团队奖励 (35%)

**函数**: `_distributeTeamReward()`

**位置**: [StakingBase.sol:1036](contracts/AE-Staking/src/abstract/StakingBase.sol#L1036)

#### 3.1 团队等级系统

团队等级由两个条件共同决定（取较低者）：

**条件 1: 团队业绩 (Team KPI)**

| 等级 | 团队业绩要求 | 奖励比例 |
|-----|------------|---------|
| V1  | 3,000 USDT | 3%      |
| V2  | 10,000 USDT | 7%     |
| V3  | 30,000 USDT | 11%    |
| V4  | 100,000 USDT | 15%   |
| V5  | 300,000 USDT | 19%   |
| V6  | 1,000,000 USDT | 23% |
| V7  | 3,000,000 USDT | 27% |
| V8  | 10,000,000 USDT | 31% |
| V9  | 30,000,000 USDT | 35% |

**条件 2: 个人质押**

| 等级 | 个人质押要求 |
|-----|------------|
| V1  | 100 USDT   |
| V2  | 300 USDT   |
| V3  | 600 USDT   |
| V4  | 1,000 USDT |
| V5  | 3,000 USDT |
| V6  | 6,000 USDT |
| V7  | 10,000 USDT |
| V8  | 15,000 USDT |
| V9  | 20,000 USDT |

**等级计算逻辑**:
```solidity
uint8 teamKpiTier = _getTierByTeamKpi(teamKPI);
uint8 personalStakeTier = _getTierByPersonalStake(personalStake);
return teamKpiTier < personalStakeTier ? teamKpiTier : personalStakeTier;
```

#### 3.2 差额奖励机制

团队奖励采用**严格差额分配**机制，避免重复发放：

```solidity
// 示例：推荐链中有 V3(11%) 和 V1(3%) 两个等级
// V3 获得: 11% - 0% = 11%
// V1 获得: 0% (因为 3% < 11%，已被更高等级占用)
```

**分配算法**:
1. 遍历推荐链（最多 30 层）
2. 记录每个成员的等级
3. 按等级从高到低分配差额奖励
4. 使用 `tierAllocated[]` 标记已分配的等级
5. 累计已分配比例 `cumulativeAllocatedRate`

**代码实现**: [StakingBase.sol:1102](contracts/AE-Staking/src/abstract/StakingBase.sol#L1102)

```solidity
if (tierRewardRate > cumulativeAllocatedRate) {
    actualRewardRate = tierRewardRate - cumulativeAllocatedRate;
} else {
    actualRewardRate = 0;  // 该等级已被更高等级占用
}
```

#### 3.3 未分配奖励处理

```solidity
uint256 marketingAmount = 0;
if (totalDistributed < fee) {
    marketingAmount = fee - totalDistributed;
    IERC20(USDT).transfer(rootAddress, marketingAmount);
}
```

**情况**:
- 推荐链为空：全部 35% 归项目方
- 推荐链等级不足：差额归项目方
- 例如：只有 V1(3%)，则 32% 归项目方

### 4. 赎回手续费 (1%)

**位置**: [StakingBase.sol:262](contracts/AE-Staking/src/abstract/StakingBase.sol#L262)

```solidity
uint256 expectedRedemptionFeeUSDT = (userPayout * 100) / 10000;  // 1%

if (expectedRedemptionFeeUSDT > 0 && feeRecipient != address(0)) {
    // 额外兑换 1% 的 AE 为 USDT 作为手续费
    (, uint256 redemptionFeeAEUsed) = _swapAEForReward(expectedRedemptionFeeUSDT);

    emit RedemptionFeeCollected(...);
}
```

**特点**:
- 从用户最终收益中扣除 1%
- 需要额外消耗 AE 代币兑换
- 发送到 `feeRecipient` 地址

### 5. 用户实际收益

```solidity
uint256 userPayout = usdtReceived - friendReward - teamFee;
uint256 finalUserPayout = userPayout - redemptionFee;

IERC20(USDT).transfer(msg.sender, finalUserPayout);
```

### 6. 完整分配示例

**假设**:
- 用户质押 1000 USDT，30天后解质押
- 计算收益: 1309 USDT
- 利息: 309 USDT
- 推荐链: V3(11%) 和 V1(3%)

**分配计算**:
```
总收益: 1309 USDT
├── 本金: 1000 USDT (返还用户)
└── 利息: 309 USDT
    ├── 好友奖励: 309 × 5% = 15.45 USDT
    ├── 团队奖励: 309 × 35% = 108.15 USDT
    │   ├── V3 获得: 309 × 11% = 33.99 USDT
    │   ├── V1 获得: 0 USDT (被 V3 覆盖)
    │   └── 项目方: 309 × 24% = 74.16 USDT (35% - 11%)
    ├── 用户收益: 309 - 15.45 - 108.15 = 185.4 USDT
    └── 赎回费: 185.4 × 1% = 1.85 USDT

用户最终收到: 1000 + 185.4 - 1.85 = 1183.55 USDT
```

## 关键限制与规则

### 1. 质押限制

#### 1.1 金额限制
```solidity
MIN_STAKE_AMOUNT = 100 ether;        // 最小 100 USDT
MAX_STAKE_LIMIT = 1000 ether;        // 单次最大 1000 USDT
MAX_USER_TOTAL_STAKE = 10000 ether;  // 用户总限额 10000 USDT
```

#### 1.2 动态限制
```solidity
function maxStakeAmount() public view returns (uint256) {
    uint256 recentInflow = getRecentNetworkInflow();  // 最近1分钟流入
    uint256 onePercentOfPool = poolReserveUsdt / 100;

    if (recentInflow > onePercentOfPool) {
        return 0;  // 流入过快，暂停质押
    } else {
        uint256 availableCapacity = onePercentOfPool - recentInflow;
        return min(availableCapacity, MAX_STAKE_LIMIT);
    }
}
```

**目的**: 防止短时间内大量资金涌入，保护池子稳定性。

#### 1.3 7天期限制
- 每个地址只能使用一次 7 天期质押
- 管理员可通过 `reset7DayStakeUsage()` 重置

### 2. 推荐系统规则

#### 2.1 绑定规则
```solidity
// 1. 只能绑定一次
if (_referrals[user] != address(0)) revert AlreadyBound();

// 2. 不能自己推荐自己
if (_referrer == user) revert CannotReferSelf();

// 3. 推荐人必须有质押（除了根地址）
if (_referrer != rootAddress && balanceOf(_referrer) <= 1 ether) {
    revert InvalidReferrer();
}
```

#### 2.2 推荐链深度
```solidity
uint8 constant MAX_REFERRAL_DEPTH = 30;  // 最多追溯 30 层
```

#### 2.3 团队业绩计算
```solidity
// 质押时增加上级团队业绩
_updateTeamInvestmentValues(sender, _amount, true);

// 解质押时减少上级团队业绩
_updateTeamInvestmentValues(sender, principalAmount, false);
```

### 3. 安全机制

#### 3.1 EOA 检查（主网）
```solidity
modifier onlyEOA() {
    if (shouldCheckEOA() && tx.origin != msg.sender)
        revert OnlyEOAAllowed();
    _;
}
```

#### 3.2 重入保护
- 使用 `unchecked` 块优化 gas
- 先更新状态，后转账（Checks-Effects-Interactions 模式）

#### 3.3 滑点保护
- 动态计算滑点容忍度
- 考虑价格影响和代币税费
- 最大滑点 20%

## 数学模型

### 1. 复利计算公式

```
最终价值 = 本金 × (1 + 日利率)^天数
```

**Solidity 实现**:
```solidity
UD60x18 compoundedAmount = principalAmount.mul(
    baseInterestRate.powu(compoundPeriods)
);
```

### 2. 收益率对比表

| 质押金额 | 期限 | 日利率 | 最终价值 | 收益 | 实际收益率 |
|---------|------|--------|---------|------|-----------|
| 1000 USDT | 7天 | 0.6% | 1043 USDT | 43 USDT | 4.3% |
| 1000 USDT | 30天 | 0.9% | 1309 USDT | 309 USDT | 30.9% |
| 1000 USDT | 90天 | 1.1% | 2695 USDT | 1695 USDT | 169.5% |
| 1000 USDT | 180天 | 1.5% | 14841 USDT | 13841 USDT | 1384.1% |
| 1000 USDT | 365天 | 2.0% | 1377408 USDT | 1376408 USDT | 137640.8% |

**注意**: 这些是理论收益，实际收益还需扣除好友奖励、团队奖励和赎回费。

### 3. 用户实际收益计算

```
实际收益 = (最终价值 - 本金) × (1 - 5% - 35%) × (1 - 1%)
         = 利息 × 60% × 99%
         = 利息 × 59.4%
```

**示例**（30天期，1000 USDT）:
```
理论利息: 309 USDT
实际收益: 309 × 59.4% ≈ 183.55 USDT
实际收益率: 18.36%
```

### 4. 流动性影响

#### 4.1 质押时添加流动性
```
USDT 流动性增加: 质押金额 × 50%
AE 流动性增加: (质押金额 × 50%) / AE价格 × (1 - 3%)
```

#### 4.2 解质押时移除流动性
```
AE 消耗量 ≈ 收益 / AE价格 × (1 + 滑点)
```

## 总结

### 优势
1. **高收益**: 日复利机制提供极高的理论收益率
2. **流动性增长**: 每次质押都增加 AE/USDT 池子流动性
3. **多层激励**: 推荐、团队、好友三重奖励机制
4. **安全保护**: 滑点保护、金额限制、流入控制

### 风险
1. **高通胀**: 极高的收益率可能导致 AE 代币通胀
2. **流动性依赖**: 解质押依赖池子有足够的 USDT 储备
3. **价格波动**: AE 价格下跌会影响实际收益
4. **复杂分配**: 多层奖励机制增加了系统复杂度

### 关键数据流
```
用户 USDT → 合约
    ↓
50% USDT + 50% AE → Uniswap 流动性池
    ↓
LP Token → 销毁 (address(0))
    ↓
用户获得 sAE 凭证
    ↓
到期后: AE → USDT (通过 Uniswap)
    ↓
分配: 好友(5%) + 团队(35%) + 赎回费(1%) + 用户(剩余)
```
