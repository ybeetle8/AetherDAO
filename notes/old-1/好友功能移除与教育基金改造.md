# 好友功能移除与教育基金改造

## 修改概述

本次修改将原有的**好友奖励机制**改造为**教育基金机制**：

- **移除功能**: 删除用户绑定好友的功能（`lockFriend`、`getFriend`）
- **资金重定向**: 原本分给好友的 5% 奖励改为分配给教育基金地址
- **配置化管理**: 教育基金地址通过配置文件管理，在部署时传入合约

    address _router,

##### 修改点 5: 修改奖励分配逻辑

```solidity
// 修改前:
function _distributeFriendReward(
    address _user,
    uint256 _interset
) private returns (uint256 fee) {
    unchecked {
        fee = (_interset * REFERRAL_REWARD_RATE) / PERCENTAGE_BASE;
    }
    address friend = getFriend(_user);
    if (friend != address(0)) {
        IERC20(USDT).transfer(friend, fee);
    } else {
        IERC20(USDT).transfer(rootAddress, fee);
    }
}

// 修改后:
function _distributeFriendReward(
    address _user,
    uint256 _interset
) private returns (uint256 fee) {
    unchecked {
        fee = (_interset * REFERRAL_REWARD_RATE) / PERCENTAGE_BASE;
    }
    // 直接将 5% 奖励转给教育基金地址
    IERC20(USDT).transfer(educationFundAddress, fee);
}
```

## 功能对比

### 修改前（好友机制）

```
用户提取利息 1000 USDT
├─ 好友奖励 (5%): 50 USDT
│  ├─ 如果已绑定好友 → 转给好友地址
│  └─ 如果未绑定好友 → 转给 rootAddress
├─ 团队奖励 (35%): 350 USDT → 分配给推荐链
└─ 用户实得 (60%): 600 USDT
```

### 修改后（教育基金）

```
用户提取利息 1000 USDT
├─ 教育基金 (5%): 50 USDT → 固定转给教育基金地址
├─ 团队奖励 (35%): 350 USDT → 分配给推荐链
└─ 用户实得 (60%): 600 USDT
```

## 关键变化

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| **5% 奖励接收方** | 用户绑定的好友（或 rootAddress） | 固定的教育基金地址 |
| **用户操作** | 可以调用 `lockFriend()` 绑定好友 | 无需任何操作 |
| **资金流向** | 动态（取决于用户是否绑定） | 固定（始终转给教育基金） |
| **合约参数** | 4 个构造函数参数 | 5 个构造函数参数 |
| **配置管理** | 无配置 | 通过 `ae-deployment-config.json` 管理 |

## 影响评估

### 对用户的影响

- ✅ **无影响**: 用户收益比例保持不变（仍为 60%）
- ✅ **简化操作**: 用户无需绑定好友，减少操作步骤
- ⚠️ **功能移除**: 用户无法再指定好友获得 5% 分成

### 对系统的影响

- ✅ **资金用途明确**: 5% 奖励统一用于教育基金
- ✅ **代码简化**: 删除好友绑定相关代码，减少维护成本
- ✅ **Gas 优化**: 减少一次条件判断和状态读取
- ✅ **配置化管理**: 教育基金地址可通过配置文件灵活调整

### 兼容性

- ⚠️ **不兼容旧版本**: 构造函数参数增加，需要重新部署
- ⚠️ **接口变化**: 删除了 `lockFriend()` 和 `getFriend()` 函数
- ✅ **核心逻辑不变**: 奖励分配比例和计算逻辑保持一致
