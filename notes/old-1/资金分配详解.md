## AE 代币交易税与手续费

### 1. 买入交易 (Buy Transaction)

**代码位置**: [AEBase.sol:716-764](contracts/AE/src/abstract/AEBase.sol#L716-L764)

#### 费用结构
```
总买入金额: 100%
├─ 销毁费 (Burn Fee): 1% → 0x...dEaD 地址
├─ 流动性费 (Liquidity Fee): 2% → LiquidityStaking 合约 (BLA 代币形式)
└─ 用户实际收到: 97%
```

#### 详细说明

| 费用类型 | 费率 | 代码常量 | 接收方 | 用途 |
|---------|------|---------|--------|------|
| 销毁费 | 1% | `BUY_BURN_FEE = 100` (1/10000) | `DEAD_ADDRESS` | 通缩机制，永久销毁 |
| 流动性费 | 2% | `BUY_LIQUIDITY_FEE = 200` (2/10000) | `liquidityStaking` | 作为 BLA 代币奖励给 LP 质押者 |
| 净收到 | 97% | - | 买家 | 用户实际获得的代币 |

#### 资金流向
```
买家支付 USDT
    ↓
Uniswap Pair (交易执行)
    ↓
AE 代币分配:
    ├─ 1% → 销毁地址 (0x...dEaD)
    ├─ 2% → LiquidityStaking 合约 (depositBLARewards)
    └─ 97% → 买家钱包
```

#### 投资记录更新
- 用户的 `userInvestment` 会增加本次买入的 USDT 成本
- 记录 `lastBuyTime` 用于冷却期检查
- 代码位置: [AEBase.sol:995-1042](contracts/AE/src/abstract/AEBase.sol#L995-L1042)

### 2. 卖出交易 (Sell Transaction)

**代码位置**: [AEBase.sol:766-871](contracts/AE/src/abstract/AEBase.sol#L766-L871)

#### 费用结构（无盈利情况）
```
卖出 AE 代币: 100%
├─ 营销费 (Marketing Fee): 1.5% → 累积到 amountMarketingFee
├─ 流动性累积费 (LP Accumulation Fee): 1.5% → 累积到 amountLPFee
└─ 净卖出: 97% → 换成 USDT
```

#### 费用结构（有盈利情况）
```
卖出 AE 代币: 100%
├─ 营销费: 1.5% → 累积
├─ 流动性累积费: 1.5% → 累积
├─ 盈利税 (Profit Tax): 25% of profit (从净卖出中扣除)
│   ├─ 40% (10/25) → LiquidityStaking (USDT 奖励)
│   └─ 60% (15/25) → nodeDividendAddress 或 marketingAddress
└─ 用户实际收到: 净额 - 盈利税
```

#### 详细说明

| 费用类型 | 费率 | 代码常量 | 接收方 | 说明 |
|---------|------|---------|--------|------|
| 营销费 | 1.5% | `SELL_MARKETING_FEE = 150` | `amountMarketingFee` (累积) | 累积后统一处理 |
| 流动性累积费 | 1.5% | `SELL_LIQUIDITY_ACCUM_FEE = 150` | `amountLPFee` (累积) | 累积后作为 BLA 奖励 |
| 盈利税 | 25% | `PROFIT_TAX_RATE = 2500` | 分配给 LS 和节点 | 仅在有盈利时收取 |

#### 盈利计算逻辑
```solidity
// 代码位置: AEBase.sol:789-801
estimatedUSDTFromSale = 净卖出金额换算的 USDT
userCurrentInvestment = 用户历史投资成本

if (estimatedUSDTFromSale > userCurrentInvestment) {
    profitAmount = estimatedUSDTFromSale - userCurrentInvestment
    profitTaxUSDT = profitAmount * 25%

    // 盈利税分配
    lsShare = profitTaxUSDT * 40% (10/25)  → LiquidityStaking
    nodeShare = profitTaxUSDT * 60% (15/25) → nodeDividendAddress
}
```

#### 资金流向
```
卖家 AE 代币
    ↓
扣除交易费:
    ├─ 1.5% → amountMarketingFee (累积)
    ├─ 1.5% → amountLPFee (累积)
    └─ 97% → 准备换成 USDT
         ↓
    计算盈利税 (如果有盈利):
         ├─ 盈利的 25% 转为 AE 代币
         ├─ 立即 swap 成 USDT
         ├─ 40% → LiquidityStaking (depositRewards)
         └─ 60% → nodeDividendAddress
         ↓
    最终 USDT → 卖家钱包
```

#### 冷却期限制
- 卖出需要满足冷却期: `block.timestamp >= lastBuyTime + coldTime`
- 默认冷却期: `coldTime = 10 seconds`
- 代码位置: [AEBase.sol:771-772](contracts/AE/src/abstract/AEBase.sol#L771-L772)

### 3. 累积费用处理机制

**代码位置**: [AEBase.sol:1144-1248](contracts/AE/src/abstract/AEBase.sol#L1144-L1248)

#### 触发条件
```
totalFees = amountMarketingFee + amountLPFee
if (totalFees >= swapAtAmount) {
    触发自动处理
}
```
- 默认阈值: `swapAtAmount = 10000 ether`

#### 处理流程
```
累积的费用 (AE 代币)
    ↓
营销费部分:
    ├─ swap 成 USDT
    └─ 转账到 marketingAddress

流动性费部分:
    ├─ 直接作为 BLA 代币
    └─ 存入 LiquidityStaking (depositBLARewards)
```

#### 安全检查
- 检查流动性池储备是否充足
- 限制单次 swap 不超过池子的 2%
- 代码位置: [AEBase.sol:1166-1203](contracts/AE/src/abstract/AEBase.sol#L1166-L1203)

## 质押系统资金分配

### 1. 质押操作 (Stake)

**代码位置**: [StakingBase.sol:208-221](contracts/AE-Staking/src/abstract/StakingBase.sol#L208-L221)

#### 质押流程
```
用户支付 USDT
    ↓
分成两半:
    ├─ 50% USDT → swap 成 AE 代币
    │   └─ 扣除 AE 买入费 (3%):
    │       ├─ 1% 销毁
    │       └─ 2% LP 奖励
    └─ 50% USDT → 保留
         ↓
    添加流动性:
         ├─ 剩余的 AE 代币 (约 48.5%)
         ├─ 剩余的 USDT (50%)
         └─ LP Token → 销毁到 0x0 地址
              ↓
         铸造 sAE (质押凭证)
```

#### 详细说明

| 步骤 | 金额 | 操作 | 说明 |
|-----|------|------|------|
| 1. 用户支付 | 100% USDT | 转入 Staking 合约 | 例如: 1000 USDT |
| 2. USDT 分配 | 50% | swap 成 AE | 500 USDT → AE |
| | 50% | 保留 | 500 USDT 保留 |
| 3. AE 买入费 | 3% | 扣除 | 从 swap 得到的 AE 中扣除 |
| | 1% | 销毁 | 永久销毁 |
| | 2% | LP 奖励 | 给 LiquidityStaking |
| 4. 添加流动性 | ~48.5% AE | 添加到池子 | 净 AE 数量 |
| | 50% USDT | 添加到池子 | 原始 USDT |
| 5. LP Token | 100% | 销毁 | 发送到 address(0) |
| 6. 铸造 sAE | 100% USDT | 质押凭证 | 按原始 USDT 金额 |

#### 质押方案

| 方案 | 期限 | 日利率 | 年化收益 (复利) | 限制 |
|-----|------|--------|----------------|------|
| 7天 | 7 days | 0.6% | ~900% | 每人仅可使用一次 |
| 30天 | 30 days | 0.9% | ~1600% | 无限制 |
| 90天 | 90 days | 1.1% | ~3600% | 无限制 |
| 180天 | 180 days | 1.5% | ~16000% | 无限制 |
| 365天 | 365 days | 2.0% | ~130000% | 无限制 |

**代码位置**: [Staking.sol:27-45](contracts/AE-Staking/src/mainnet/Staking.sol#L27-L45)

#### 质押限制
- 单次质押上限: `MAX_STAKE_LIMIT = 1000 USDT`
- 用户总质押上限: `MAX_USER_TOTAL_STAKE = 10000 USDT`
- 网络流入限制: 1分钟内流入不能超过池子的 1%
- 代码位置: [StakingBase.sol:62-63](contracts/AE-Staking/src/abstract/StakingBase.sol#L62-L63)

### 2. 解质押操作 (Unstake)

**代码位置**: [StakingBase.sol:223-287](contracts/AE-Staking/src/abstract/StakingBase.sol#L223-L287)

#### 解质押流程
```
用户发起解质押
    ↓
计算收益 (复利):
    本金 * (1 + 日利率)^天数
    ↓
从池子中 swap AE → USDT:
    ├─ 使用 swapTokensForExactTokens
    └─ 获得精确的 USDT 数量
         ↓
    分配收益:
         ├─ 好友奖励: 利息的 5%
         ├─ 团队奖励: 利息的 35% (最高)
         ├─ 赎回费: 用户收益的 1%
         └─ 用户实际收到: 剩余部分
              ↓
         回收 AE 代币:
              └─ 调用 AE.recycle() 回收到池子
```

#### 详细费用分配

| 费用类型 | 费率 | 计算基数 | 接收方 | 说明 |
|---------|------|---------|--------|------|
| 好友奖励 | 5% | 利息收益 | friend 或 rootAddress | 固定 5% |
| 团队奖励 | 最高 35% | 利息收益 | 推荐链上的团队成员 | 差额分配 |
| 赎回费 | 1% | 用户最终收益 | feeRecipient | 从用户收益中扣除 |
| 用户收益 | 剩余 | - | 用户 | 扣除所有费用后 |

#### 团队奖励分配机制

**代码位置**: [StakingBase.sol:1012-1163](contracts/AE-Staking/src/abstract/StakingBase.sol#L1012-L1163)

##### 团队等级与奖励比例

| 等级 | 团队业绩要求 | 奖励比例 | 累积比例 |
|-----|------------|---------|---------|
| V1 | 10,000 USDT | 5% | 5% |
| V2 | 50,000 USDT | 10% | 10% |
| V3 | 200,000 USDT | 15% | 15% |
| V4 | 500,000 USDT | 20% | 20% |
| V5 | 1,000,000 USDT | 25% | 25% |
| V6 | 2,500,000 USDT | 30% | 30% |
| V7 | 5,000,000 USDT | 35% | 35% |

**代码位置**: [Staking.sol:69-95](contracts/AE-Staking/src/mainnet/Staking.sol#L69-L95)

##### 差额分配规则

团队奖励采用**严格差额分配**机制:

```
示例: 用户 A 解质押，利息收益 1000 USDT
推荐链: A → B(V3) → C(V5) → D(V2)

团队奖励总额 = 1000 * 35% = 350 USDT

分配计算:
├─ B (V3, 15%): 获得 15% - 0% = 15% → 150 USDT
├─ C (V5, 25%): 获得 25% - 15% = 10% → 100 USDT
├─ D (V2, 10%): 10% < 25%，无奖励 → 0 USDT
└─ 剩余: 35% - 25% = 10% → 100 USDT → rootAddress

实际分配:
├─ B: 150 USDT
├─ C: 100 USDT
├─ rootAddress: 100 USDT
└─ 总计: 350 USDT
```

##### 资格要求
- 必须是 Preacher (质押金额 ≥ 200 USDT)
- 必须达到对应的团队业绩
- 只有更高等级才能获得差额奖励

#### 解质押资金流向
```
用户解质押请求
    ↓
计算总收益 (本金 + 利息)
    ↓
从 Uniswap Pair swap AE → USDT
    ├─ 使用 swapTokensForExactTokens
    └─ 获得精确 USDT 数量
         ↓
    分配流程:
         ├─ 好友奖励 (5% of 利息) → friend 地址
         ├─ 团队奖励 (最高 35% of 利息) → 推荐链成员
         ├─ 赎回费 (1% of 用户收益) → feeRecipient
         └─ 剩余 USDT → 用户钱包
              ↓
         回收使用的 AE:
              └─ AE.recycle() → 回到 Uniswap Pair
```

#### 赎回费详解

**代码位置**: [StakingBase.sol:246-265](contracts/AE-Staking/src/abstract/StakingBase.sol#L246-L265)

```
赎回费 = 用户最终收益 * 1%

计算示例:
├─ 总 USDT 收到: 1000 USDT
├─ 好友奖励: 50 USDT (5% of 利息)
├─ 团队奖励: 350 USDT (35% of 利息)
├─ 用户应得: 600 USDT
└─ 赎回费: 600 * 1% = 6 USDT → feeRecipient
    └─ 用户实际收到: 594 USDT
```

## 资金流向图

### 买入交易完整流向

```
用户 USDT
    ↓
Uniswap Router
    ↓
Uniswap Pair (AE/USDT)
    ↓
AE 代币分配:
    ├─ 1% → 0x...dEaD (销毁)
    ├─ 2% → LiquidityStaking 合约
    │        └─ 作为 BLA 奖励分配给 LP 质押者
    └─ 97% → 用户钱包
```

### 卖出交易完整流向 (有盈利)

```
用户 AE 代币
    ↓
扣除交易费:
    ├─ 1.5% → amountMarketingFee (AE 合约累积)
    ├─ 1.5% → amountLPFee (AE 合约累积)
    └─ 97% → 继续处理
         ↓
    计算盈利税:
         ├─ 盈利部分的 25% 转为 AE
         ├─ swap 成 USDT
         ├─ 40% → LiquidityStaking (USDT 奖励)
         └─ 60% → nodeDividendAddress
              ↓
         剩余 AE → Uniswap Pair
              ↓
         换成 USDT → 用户钱包
```

### 质押完整流向

```
用户 USDT (例如: 1000 USDT)
    ↓
Staking 合约
    ↓
分成两半:
    ├─ 500 USDT → Uniswap Router
    │              ↓
    │         swap 成 AE (扣除 3% 费用)
    │              ├─ 1% 销毁
    │              └─ 2% LP 奖励
    │              ↓
    │         获得约 485 AE
    │
    └─ 500 USDT → 保留
         ↓
    添加流动性:
         ├─ 485 AE
         ├─ 500 USDT
         └─ LP Token → address(0) (销毁)
              ↓
         铸造 1000 sAE → 用户
```

### 解质押完整流向

```
用户发起解质押
    ↓
计算收益: 本金 1000 → 收益 2000 (利息 1000)
    ↓
Staking 合约从 Pair swap AE → 2000 USDT
    ↓
分配:
    ├─ 好友奖励: 1000 * 5% = 50 USDT → friend
    ├─ 团队奖励: 1000 * 35% = 350 USDT → 推荐链
    │   ├─ V3 成员: 150 USDT
    │   ├─ V5 成员: 100 USDT
    │   └─ rootAddress: 100 USDT
    ├─ 用户应得: 2000 - 50 - 350 = 1600 USDT
    ├─ 赎回费: 1600 * 1% = 16 USDT → feeRecipient
    └─ 用户实际收到: 1584 USDT
         ↓
    回收 AE:
         └─ 使用的 AE → recycle() → Uniswap Pair
```

### 累积费用处理流向

```
累积的 AE 代币费用 (≥ 10000 AE)
    ↓
分类处理:
    ├─ amountMarketingFee
    │   ├─ swap 成 USDT
    │   └─ 转账到 marketingAddress
    │
    └─ amountLPFee
        ├─ 直接作为 BLA 代币
        └─ depositBLARewards() → LiquidityStaking
            └─ 分配给 LP 质押者
```

## 总结

### 买入交易
- **总费用**: 3%
- **销毁**: 1%
- **LP 奖励**: 2%
- **用户净收到**: 97%

### 卖出交易 (无盈利)
- **总费用**: 3%
- **营销费**: 1.5% (累积)
- **LP 费**: 1.5% (累积)
- **用户净收到**: 97%

### 卖出交易 (有盈利)
- **总费用**: 3% + 盈利的 25%
- **营销费**: 1.5% (累积)
- **LP 费**: 1.5% (累积)
- **盈利税**: 盈利的 25%
  - 40% → LiquidityStaking
  - 60% → nodeDividendAddress
- **用户净收到**: 97% - 盈利税

### 质押
- **LP Token**: 100% 销毁到 address(0)
- **sAE 凭证**: 按原始 USDT 金额铸造
- **收益**: 每日复利，最高 2% 日利率

### 解质押
- **好友奖励**: 利息的 5%
- **团队奖励**: 利息的最高 35% (差额分配)
- **赎回费**: 用户收益的 1%
- **用户收益**: 扣除所有费用后的剩余部分
