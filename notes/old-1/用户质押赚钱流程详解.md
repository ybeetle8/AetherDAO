## 系统概览

AetherDAO 质押系统是一个基于 BSC 链的 DeFi 质押协议，用户通过质押 USDT 获得收益。系统的核心特点：

- **质押代币**: USDT
- **收益代币**: AE (通过 Uniswap V2 兑换为 USDT)
- **质押凭证**: sAE (不可转让的质押代币)
- **推荐系统**: 多层级推荐奖励
- **团队奖励**: 7 个等级的团队业绩奖励

## 准备阶段

### 1. 绑定推荐关系

**必须先绑定推荐人才能质押！**

```solidity
function lockReferral(address _referrer) external
```

**操作步骤**:
1. 调用 `lockReferral()` 函数
2. 传入推荐人地址（如果传 `address(0)` 则绑定到根地址）
3. 推荐人必须满足条件：已质押至少 1 USDT

**限制条件**:
- 每个地址只能绑定一次，不可更改
- 不能自己推荐自己
- 推荐人必须已经有质押记录（余额 > 1 USDT）

**代码位置**: [StakingBase.sol:266-295](contracts/AE-Staking/src/abstract/StakingBase.sol#L266-L295)

### 2. 绑定好友账户（可选）

```solidity
function lockFriend(address _friend) external
```

**作用**:
- 绑定一个好友地址，该地址将获得你提取收益时的 5% 直推奖励
- 如果不绑定，这 5% 将归根地址所有

**代码位置**: [StakingBase.sol:301-311](contracts/AE-Staking/src/abstract/StakingBase.sol#L301-L311)

## 质押流程

### 1. 选择质押方案

系统提供 4 种质押方案：

| 方案编号 | 锁定期 | 日化收益率 | 总收益率 | APY |
|---------|--------|-----------|---------|-----|
| 0 | 1 天 | 0.3% | 0.3% | ~109.5% |
| 1 | 7 天 | 0.6% | 4.28% | ~219% |
| 2 | 15 天 | 1.0% | 16.1% | ~365% |
| 3 | 30 天 | 1.5% | 56.31% | ~547.5% |

**收益计算方式**: 复利计算（每日复利）

**代码位置**: [Staking.sol:27-41](contracts/AE-Staking/src/mainnet/Staking.sol#L27-L41)

### 2. 执行质押

```solidity
function stake(uint160 _amount, uint8 _stakeIndex) external
```

**参数**:
- `_amount`: 质押的 USDT 数量（单位：wei，例如 100 USDT = 100 * 10^18）
- `_stakeIndex`: 质押方案编号（0-3）

**质押限制**:
- 单次质押上限：1000 USDT
- 用户总质押上限：10000 USDT
- 网络流量限制：最近 1 分钟的质押量不能超过流动池 USDT 储备的 1%

**质押过程**:
1. 用户授权合约使用 USDT
2. 合约收取用户的 USDT
3. 将 50% 的 USDT 兑换为 AE 代币
4. 将剩余 50% USDT 和兑换的 AE 添加到 Uniswap V2 流动池
5. 为用户铸造 sAE 质押凭证（数量等于质押的 USDT 数量）
6. 记录质押信息

**代码位置**: [StakingBase.sol:193-198](contracts/AE-Staking/src/abstract/StakingBase.sol#L193-L198)

### 3. 质押后的状态

- 用户获得 sAE 代币（不可转让）
- 质押记录被保存，包含：
  - 质押时间
  - 质押金额
  - 质押方案
  - 提取状态
- 团队业绩更新：推荐链上的所有上级的团队业绩增加

## 收益计算

### 复利计算公式

```
当前价值 = 本金 × (1 + 日化收益率)^天数
```

**示例**:
- 质押 1000 USDT，选择方案 3（30天，1.5% 日化）
- 30 天后价值 = 1000 × (1.015)^30 = 1563.1 USDT
- 收益 = 563.1 USDT

**代码位置**: [StakingBase.sol:1139-1168](contracts/AE-Staking/src/abstract/StakingBase.sol#L1139-L1168)

### 查询当前收益

```solidity
// 查询总价值（本金 + 收益）
function balanceOf(address account) external view returns (uint256)

// 查询本金
function principalBalance(address account) external view returns (uint256)

// 查询已赚取的利息
function earnedInterest(address account) external view returns (uint256)

// 查询特定质押记录的收益
function rewardOfSlot(address user, uint8 index) external view returns (uint256)
```

## 提取流程

### 1. 检查是否可以提取

```solidity
function canWithdrawStake(address user, uint256 stakeIndex) external view returns (bool)
```

**提取条件**:
- 质押时间已达到锁定期
- 该质押记录未被提取过

### 2. 执行提取

```solidity
function unstake(uint256 stakeIndex) external returns (uint256 totalReward)
```

**提取过程详解**:

#### 步骤 1: 计算收益
- 根据质押时间和方案计算复利收益
- 例如：本金 1000 USDT，30天后价值 1563.1 USDT

#### 步骤 2: 兑换 AE 为 USDT
- 合约使用 AE 代币通过 Uniswap V2 兑换为 USDT
- 兑换目标金额 = 计算出的总价值（1563.1 USDT）
- 实际兑换可能因滑点略有差异

#### 步骤 3: 分配收益

假设实际兑换得到 1560 USDT，利息 = 1560 - 1000 = 560 USDT

**收益分配结构**:

1. **好友奖励（5%）**: 560 × 5% = 28 USDT
   - 支付给绑定的好友地址
   - 如未绑定好友，支付给根地址

2. **团队奖励（35%）**: 560 × 35% = 196 USDT
   - 按照推荐链上的团队等级分配
   - 详见[团队奖励机制](#团队奖励机制)

3. **赎回手续费（1%）**: 用户实际收到金额的 1%
   - 从用户应得部分扣除
   - 支付给 feeRecipient 地址

4. **用户实际收到**: 1560 - 28 - 196 = 1336 USDT
   - 扣除 1% 赎回费后最终到账

**代码位置**: [StakingBase.sol:200-264](contracts/AE-Staking/src/abstract/StakingBase.sol#L200-L264)

#### 步骤 4: 更新状态
- 销毁用户的 sAE 代币
- 标记质押记录为已提取
- 更新推荐链上所有上级的团队业绩（减少）
- 记录提取历史

## 推荐奖励机制

### 直推奖励（好友奖励）

- **奖励比例**: 利息的 5%
- **获得者**: 用户绑定的好友地址
- **触发时机**: 用户提取收益时
- **无需条件**: 任何地址都可以获得

**示例**:
- 用户 A 绑定好友 B
- 用户 A 提取时获得 560 USDT 利息
- 好友 B 自动获得 560 × 5% = 28 USDT

**代码位置**: [StakingBase.sol:971-984](contracts/AE-Staking/src/abstract/StakingBase.sol#L971-L984)

## 团队奖励机制

### 1. 团队业绩（Team KPI）

**定义**: 直接和间接推荐的所有下级的质押总额（不包括自己的质押）

**计算方式**:
- 当下级质押时，推荐链上所有上级的 Team KPI 增加
- 当下级提取时，推荐链上所有上级的 Team KPI 减少

**代码位置**: [StakingBase.sol:776-792](contracts/AE-Staking/src/abstract/StakingBase.sol#L776-L792)

### 2. 团队等级

根据 Team KPI 划分 7 个等级：

| 等级 | Team KPI 要求 | 奖励比例 | 差额比例 |
|-----|--------------|---------|---------|
| V1 | 10,000 USDT | 5% | 5% |
| V2 | 50,000 USDT | 10% | 5% |
| V3 | 200,000 USDT | 15% | 5% |
| V4 | 500,000 USDT | 20% | 5% |
| V5 | 1,000,000 USDT | 25% | 5% |
| V6 | 2,500,000 USDT | 30% | 5% |
| V7 | 5,000,000 USDT | 35% | 5% |

**代码位置**: [Staking.sol:61-87](contracts/AE-Staking/src/mainnet/Staking.sol#L61-L87)

### 3. 传教士资格（Preacher）

**定义**: 质押金额达到 200 USDT 的用户

**作用**: 只有传教士才能获得团队奖励

**代码位置**: [StakingBase.sol:641-643](contracts/AE-Staking/src/abstract/StakingBase.sol#L641-L643)

### 4. 差额奖励分配机制

**核心原则**:
- 总奖励池 = 利息的 35%
- 按照推荐链从下往上查找，每个等级只奖励一次
- 使用差额计算：当前等级奖励比例 - 已分配的累计比例

**分配流程**:

1. 遍历推荐链（最多 30 层）
2. 对于每个上级：
   - 检查是否是传教士（质押 ≥ 200 USDT）
   - 计算其团队等级
   - 如果该等级未被分配：
     - 计算差额奖励 = 当前等级比例 - 已分配累计比例
     - 发放奖励
     - 标记该等级已分配
3. 未分配的部分归根地址

**代码位置**: [StakingBase.sol:1052-1137](contracts/AE-Staking/src/abstract/StakingBase.sol#L1052-L1137)

### 5. 团队奖励示例

**场景**: 用户 E 提取，利息 1000 USDT，团队奖励池 = 1000 × 35% = 350 USDT

**推荐链结构**:
```
E (用户)
  ↓ 推荐人
D (Team KPI: 8,000, 质押: 150) - 不是传教士
  ↓ 推荐人
C (Team KPI: 60,000, 质押: 300) - V2 等级，是传教士
  ↓ 推荐人
B (Team KPI: 250,000, 质押: 500) - V3 等级，是传教士
  ↓ 推荐人
A (Team KPI: 6,000,000, 质押: 1000) - V7 等级，是传教士
```

**分配过程**:

1. **D**: Team KPI 8,000 < 10,000，等级 0，不是传教士 → 跳过

2. **C**: Team KPI 60,000，V2 等级，是传教士
   - V2 奖励比例 = 10%
   - 已分配累计 = 0%
   - 差额 = 10% - 0% = 10%
   - 获得奖励 = 1000 × 10% = 100 USDT
   - 已分配累计更新为 10%

3. **B**: Team KPI 250,000，V3 等级，是传教士
   - V3 奖励比例 = 15%
   - 已分配累计 = 10%
   - 差额 = 15% - 10% = 5%
   - 获得奖励 = 1000 × 5% = 50 USDT
   - 已分配累计更新为 15%

4. **A**: Team KPI 6,000,000，V7 等级，是传教士
   - V7 奖励比例 = 35%
   - 已分配累计 = 15%
   - 差额 = 35% - 15% = 20%
   - 获得奖励 = 1000 × 20% = 200 USDT
   - 已分配累计更新为 35%

**总计**:
- C 获得: 100 USDT
- B 获得: 50 USDT
- A 获得: 200 USDT
- 总分配: 350 USDT（全部分配完毕）

## 完整示例

### 场景设定

**角色**:
- Alice: 推荐人，Team KPI 100,000 USDT，质押 500 USDT（V2 等级，传教士）
- Bob: 用户，新加入

### 步骤 1: Bob 准备质押

1. **绑定推荐关系**:
   ```solidity
   Bob.lockReferral(Alice的地址)
   ```

2. **绑定好友**（可选）:
   ```solidity
   Bob.lockFriend(Charlie的地址)
   ```

### 步骤 2: Bob 质押

1. **选择方案**: 方案 3（30天，1.5% 日化）
2. **质押金额**: 1000 USDT
3. **授权 USDT**:
   ```solidity
   USDT.approve(StakingContract, 1000 * 10^18)
   ```
4. **执行质押**:
   ```solidity
   Staking.stake(1000 * 10^18, 3)
   ```

**结果**:
- Bob 获得 1000 sAE 代币
- 500 USDT 兑换为 AE
- 500 USDT + AE 添加到流动池
- Alice 的 Team KPI 增加 1000 USDT

### 步骤 3: 等待 30 天

- Bob 的质押价值每天增长 1.5%
- 30 天后价值 = 1000 × (1.015)^30 ≈ 1563.1 USDT

### 步骤 4: Bob 提取

1. **检查是否可提取**:
   ```solidity
   Staking.canWithdrawStake(Bob的地址, 0) // 返回 true
   ```

2. **执行提取**:
   ```solidity
   Staking.unstake(0)
   ```

**提取过程**:

1. **计算收益**: 1563.1 USDT
2. **兑换 AE**: 假设实际兑换得到 1560 USDT
3. **利息**: 1560 - 1000 = 560 USDT

**收益分配**:

- **好友奖励**: 560 × 5% = 28 USDT → Charlie
- **团队奖励**: 560 × 35% = 196 USDT
  - Alice (V2, 传教士): 560 × 10% = 56 USDT
  - 剩余 140 USDT → 根地址（因为没有更高等级的上级）
- **用户收到**: 1560 - 28 - 196 = 1336 USDT
- **赎回手续费**: 约 13.36 USDT（1%）→ feeRecipient
- **Bob 最终到账**: 约 1322.64 USDT

**状态更新**:
- Bob 的 sAE 被销毁
- Alice 的 Team KPI 减少 1000 USDT
- 提取记录被保存

### 步骤 5: 查询历史

```solidity
// 查询提取历史
Staking.getWithdrawalHistory(Bob的地址)

// 返回包含以下信息的记录:
// - 提取时间
// - 本金: 1000 USDT
// - 计算收益: 1563.1 USDT
// - 实际兑换: 1560 USDT
// - 使用的 AE 数量
// - 好友奖励: 28 USDT
// - 团队奖励: 196 USDT
// - 用户实际收到: 1336 USDT
// - 利息: 560 USDT
```

## 关键要点总结

### 用户赚钱的方式

1. **质押收益**:
   - 主要收入来源
   - 复利计算，收益率高
   - 锁定期越长，收益率越高

2. **好友奖励**:
   - 下级提取时获得其利息的 5%
   - 被动收入，无需条件

3. **团队奖励**:
   - 需要成为传教士（质押 ≥ 200 USDT）
   - 需要发展团队（Team KPI）
   - 差额奖励机制，等级越高收益越多
   - 最高可获得下级利息的 35%

### 风险提示

1. **流动性风险**:
   - 质押期间资金锁定，不能提前提取
   - 提取时需要通过 AE/USDT 交易对兑换，可能有滑点

2. **智能合约风险**:
   - 合约代码需要审计
   - 管理员权限（owner）可以紧急提取资金

3. **经济模型风险**:
   - 高收益率依赖于 AE 代币的供应和流动性
   - 需要持续的新用户加入维持系统运转

### 最佳实践

1. **选择合适的质押方案**: 根据资金使用计划选择锁定期
2. **绑定好友**: 不要浪费 5% 的直推奖励
3. **发展团队**: 成为传教士并提升团队等级以获得更多收益
4. **分散质押**: 不要一次性质押全部资金，可以分批质押不同方案
5. **关注流动性**: 提取前查看 AE/USDT 流动池深度
