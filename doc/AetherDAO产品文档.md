# AetherDAO 产品文档

## 一、产品简介

AetherDAO 是一个运行在 BSC（币安智能链）上的去中心化金融（DeFi）平台，围绕 **AE 代币** 构建，集成了代币交易、USDT 质押理财、推荐人团队奖励三大核心功能模块。

平台的设计目标：
- 通过买卖税收机制持续为代币注入流动性并销毁通缩
- 通过质押系统为用户提供复利收益
- 通过推荐人体系激励社区增长

---

## 二、核心功能模块

### 2.1 AE 代币交易

AE 是平台的原生代币，通过 PancakeSwap（Uniswap V2）与 USDT 组成交易对。所有买卖交易自动收取手续费，用于生态建设。

#### 买入 AE

用户通过 PancakeSwap 用 USDT 购买 AE 时，自动扣除 **3% 买入税**：

| 去向 | 比例 | 说明 |
|------|------|------|
| 节点分红池 | 2% | 分配给节点持有者 |
| 社区分红池 | 1% | 社区奖励基金 |

用户实际到账金额 = 购买金额 × 97%

#### 卖出 AE

卖出时包含两部分税收：

**固定税（3%）**：

| 去向 | 比例 | 说明 |
|------|------|------|
| 营销基金 | 1.5% | 用于项目推广运营 |
| 销毁 | 1.5% | 永久销毁，减少流通量 |

**利润税（盈利部分的 25%）**：

系统会追踪每个用户的历史买入成本。卖出时如果产生利润，对盈利部分额外收取 25% 的利润税，分配如下：

| 去向 | 比例 | 说明 |
|------|------|------|
| 周 Top15 奖励 | 40% | 每周交易排名前15名奖励 |
| 流动性增强 | 60% | 自动买入 AE 并添加流动性，LP 烧毁 |

> 举例：用户投入 1000 USDT 买入 AE，后以 1500 USDT 卖出。利润为 500 USDT，利润税 = 500 × 25% = 125 USDT。

#### 冷却机制

买入 AE 后 **10 秒内不可卖出**，防止闪电贷和机器人套利。

#### 预售与延迟购买

- **预售期**：项目启动后 30 天内为预售阶段
- **延迟购买期**：特定条件下启用 30 天延迟购买限制

### 2.2 USDT 质押理财

用户将 USDT 质押到平台，获得每日复利收益。

#### 质押规则

| 规则 | 说明 |
|------|------|
| 最低质押 | 100 USDT |
| 单次上限 | 1,000 USDT |
| 总质押上限 | 每个用户最多 10,000 USDT |
| 结算方式 | 每日复利 |

#### 质押期限与日收益率

| 质押期 | 日收益率 | 备注 |
|--------|---------|------|
| 7 天   | 0.6%    | 每个用户仅能使用一次 |
| 30 天  | 0.9%    | - |
| 90 天  | 1.1%    | - |
| 180 天 | 1.5%    | - |
| 365 天 | 2.0%    | - |

收益按复利计算，即每天的收益会加入本金继续生息。

> 举例：质押 1000 USDT，选择 30 天期，日利率 0.9%。
> 30 天后总收益 = 1000 × (1.009^30 - 1) ≈ 308.9 USDT

#### 质押资金流向

用户质押的 USDT 不是简单存放，而是自动参与流动性建设：

```
用户质押 1000 USDT
├── 500 USDT → 在 PancakeSwap 兑换为 AE 代币
├── 500 USDT + 对应的 AE → 添加为交易对流动性
└── 获得的 LP Token → 永久烧毁（不可撤回）
```

这意味着每一笔质押都在为 AE 代币增加流动性深度，同时烧毁 LP 保证流动性永久锁定。

#### 到期赎回

质押到期后，用户可以赎回本金和收益。赎回时系统以 AE 代币形式结算收益，自动兑换为 USDT 发放给用户。

赎回时的手续费分配：

| 去向 | 比例 | 说明 |
|------|------|------|
| 教育基金 | 5% | 用于社区教育和培训 |
| 团队奖励 | 最高 35% | 分配给推荐链上的团队领导 |
| 赎回手续费 | 5% | 平台运营费用 |
| 用户到手 | 剩余部分 | 实际收到的 USDT |

#### 提前提取利息

质押期间，用户可以随时提取已产生的利息，无需等到到期：

- 仅提取利息部分，本金继续锁定生息
- 手续费结构与到期赎回相同（教育基金 5% + 团队奖励 + 赎回费 5%）
- 已提取的利息不再重复计算

### 2.3 推荐人体系

平台内置多级推荐关系系统，鼓励用户邀请新人参与。

#### 绑定推荐人

- 每个用户可以绑定一个推荐人，**一旦绑定不可更改**
- 推荐人本身必须已经在链上绑定过推荐关系
- 不允许自我推荐，不允许形成循环引用
- 推荐链最大深度为 30 级

#### 推荐链结构示例

```
根节点（Root）
├── Alice
│   ├── Bob
│   │   ├── Dave
│   │   └── Eve
│   └── Charlie
│       └── Frank
└── Grace
```

当 Dave 赎回质押产生收益时，团队奖励沿推荐链向上分配给 Bob → Alice → Root。

#### 教育基金

每次用户赎回或提取利息时，5% 的收益自动转入项目方教育基金专属地址，用于社区教育和培训，无需用户操作。

### 2.4 团队等级与奖励

#### 等级体系

用户等级由 **两个维度** 共同决定，取较低者：

**维度一：团队 KPI 等级**（团队所有下级的质押总额）

| 等级 | 团队质押总额门槛 |
|------|----------------|
| V1 | 3,000 USDT |
| V2 | 10,000 USDT |
| V3 | 30,000 USDT |
| V4 | 100,000 USDT |
| V5 | 300,000 USDT |
| V6 | 1,000,000 USDT |
| V7 | 3,000,000 USDT |
| V8 | 10,000,000 USDT |
| V9 | 30,000,000 USDT |

**维度二：个人质押等级**（用户自身当前活跃的质押总额）

| 等级 | 个人质押要求 |
|------|------------|
| V1 | 100 USDT |
| V2 | 300 USDT |
| V3 | 600 USDT |
| V4 | 1,000 USDT |
| V5 | 3,000 USDT |
| V6 | 6,000 USDT |
| V7 | 10,000 USDT |
| V8 | 15,000 USDT |
| V9 | 20,000 USDT |

> 举例：某用户团队 KPI 达到 V5（30万 USDT），但个人只质押了 500 USDT（V2），则该用户实际等级为 V2。
> 这保证了获得高等级奖励的用户自身必须有足够的参与度。

#### 各等级的团队奖励比例

| 等级 | 奖励比例 |
|------|---------|
| V1 | 3% |
| V2 | 7% |
| V3 | 11% |
| V4 | 15% |
| V5 | 19% |
| V6 | 23% |
| V7 | 27% |
| V8 | 31% |
| V9 | 35% |

#### 差额分配机制

团队奖励采用**严格差额制**，沿推荐链向上分配，每一级只拿与下一级的差额部分：

**示例**：用户 Dave 赎回质押，产生 1000 USDT 利息

```
团队奖励池 = 1000 × 35% = 350 USDT

推荐链：Dave → Bob(V3) → Alice(V5) → Root

分配过程：
├── Bob（V3，奖励比例 11%）
│   差额 = 11% - 0%（下面没有更高等级）= 11%
│   获得 = 350 × 11% / 35% = 110 USDT
│
├── Alice（V5，奖励比例 19%）
│   差额 = 19% - 11%（Bob 已拿走 11%）= 8%
│   获得 = 350 × 8% / 35% = 80 USDT
│
└── Root（根节点）
    获得 = 350 - 110 - 80 = 160 USDT（剩余全部）
```

这种机制保证了：
- 越高等级的领导人获得越多奖励
- 但必须是"增量"贡献，不会重复计算
- 未被分配的部分归入根节点

#### 布道者身份

当用户的质押总额 >= 200 USDT 时，自动获得"布道者"身份。布道者可以享受推荐人体系的完整权益。

## 三、用户操作流程

### 3.1 新用户入门

```
1. 准备 BSC 钱包（如 MetaMask）和 USDT
2. 通过邀请链接绑定推荐人（一次性操作）
3. 选择参与方式：
   ├── 直接交易：在 PancakeSwap 买卖 AE 代币
   └── 质押理财：将 USDT 质押到平台赚取复利收益
```

### 3.2 质押操作流程

```
质押：
1. 选择质押期限（7/30/90/180/365 天）
2. 输入质押金额（100~1000 USDT，总计不超过 10000 USDT）
3. 授权 USDT 并确认交易
4. 系统自动完成流动性添加和记录

提取利息（可选）：
1. 查看当前可提取利息
2. 确认提取，本金继续生息

到期赎回：
1. 质押到期后，点击赎回
2. 系统计算总收益，扣除手续费
3. USDT 到账
```

### 3.3 推荐人操作流程

```
1. 通过邀请链接或手动输入推荐人地址
2. 确认绑定（链上交易，不可撤销）
3. 开始质押后，推荐链上的领导人自动获得团队奖励
```

## 四、经济模型总览

### 4.1 资金流向图

```
         用户买入 AE
              │
    ┌─────────┴─────────┐
    │                     │
  97% → 用户获得 AE    3% → 税收
                          ├── 2% 节点分红池
                          └── 1% 社区分红池

         用户卖出 AE
              │
    ┌─────────┴─────────────────┐
    │                             │
  扣税后 → 用户获得 USDT       税收
                                 ├── 固定 3%
                                 │   ├── 1.5% 营销
                                 │   └── 1.5% 销毁
                                 └── 利润税 25%（仅盈利部分）
                                     ├── 60% 销毁
                                     ├── 15% 流动性
                                     ├── 15% 周 Top15
                                     └── 10% 营销

         用户质押 USDT
              │
    ┌─────────┴─────────┐
    │                     │
  50% → 兑换 AE        50% → 保留 USDT
    │                     │
    └────── 合并 ─────────┘
              │
        添加流动性（LP 烧毁）

         用户赎回收益
              │
    ┌─────────┴─────────────────┐
    │                             │
  剩余 → 用户到手 USDT         手续费
                                 ├── 5% 教育基金
                                 ├── ≤35% 团队奖励
                                 └── 5% 赎回费
```

### 4.2 通缩机制

AE 代币通过多个途径持续通缩：

1. **卖出固定销毁**：每笔卖出的 1.5% 直接销毁
2. **利润税销毁**：盈利税中 60% 买入 AE 后销毁
3. **LP 永久锁定**：质押产生的 LP Token 全部烧毁，流动性不可撤回
4. **利润税流动性**：盈利税中 15% 添加流动性并烧毁 LP

### 4.3 流动性增长机制

1. 每笔质押都会将 USDT 和 AE 添加为流动性
2. 卖出利润税的 15% 自动添加流动性
3. 所有 LP Token 烧毁，流动性只增不减

## 六、平台特色

### 流动性永久锁定
所有通过质押或利润税产生的 LP Token 全部烧毁，保证流动性只增不减，为代币价格提供持续支撑。

### 复利收益
质押收益按每日复利计算，相比单利模式可为用户带来更高的实际收益。

### 双维度等级制
团队等级同时考量团队业绩和个人投入，避免"只推荐不投入"的空转行为。

### 差额制团队奖励
公平的差额分配机制，保证每一级只拿自己等级对应的增量奖励，避免上级过度截留。

### 多重通缩
卖出销毁、利润税销毁、LP锁定等多重通缩机制持续减少代币流通量。

### 利息灵活提取
质押期间可随时提取已产生利息，无需等待到期，提高资金灵活性。
